# GA4 — ตารางกรอก Custom Definitions

> สร้าง 22 ส.ค. 2569 · property `CEO AI Thailand` (G-CHJ99RY1Q1)
> เส้นทางในหน้า GA4: **การตั้งค่าพร็อพเพอร์ตี้ → การแสดงข้อมูล → คำจำกัดความที่กำหนดเอง**
> 🟢 ชื่อพารามิเตอร์ทุกตัวสแกนจากไฟล์จริงใน `src/` (ยกเว้นเทสต์) — ไม่ได้เขียนจากความจำ

## ⚠️ ตัวที่ถูกเปลี่ยนชื่อระหว่างทาง — ห้ามใส่ชื่อในโค้ด

`src/lib/analytics.ts` มี `GA_RESERVED` ที่ **เปลี่ยนชื่อพารามิเตอร์ที่ชนกับระบบ attribution ของ GA4**
ก่อนส่ง (เพราะเคยทำให้รายงานแหล่งที่มาเพี้ยนทั้งบัญชี — `js_error` ที่ส่ง `source:'react.ErrorBoundary'`
ไปโผล่เป็น session source)

| โค้ดเขียน | GA4 ได้รับจริง |
|---|---|
| `source` | **`ev_source`** |
| `medium` | **`ev_medium`** |

⇒ ลงทะเบียนด้วยชื่อในคอลัมน์ขวาเท่านั้น ไม่งั้นได้ `(not set)` ตลอดไป

## ✅ ตรวจกับกฎทางการของ Google แล้ว (22 ส.ค. 2569)

อ้างอิง: [GA4] About custom dimensions and metrics · [GA4] Cardinality

| กฎของ Google | รายการของเราผ่านไหม |
|---|---|
| ค่าไม่ซ้ำเกิน **500 ค่า/วัน/มิติ** → ข้อมูลส่วนเกินยุบเป็นแถว `(other)` | 🟢 ผ่าน — ตัวที่มีค่ามากที่สุดคือ `step` (~27 ค่า) · ที่เหลืออยู่ระหว่าง 2–14 ค่า |
| **ห้ามลงทะเบียนตัวระบุที่ไม่ซ้ำ** (session id / transaction id / เวลา / user agent) | 🟢 ผ่าน — ตาราง ③ สั่งห้าม `transaction_id` ไว้แล้ว |
| ใช้กับ **ข้อมูลเชิงหมวดหมู่** เท่านั้น | 🟢 ผ่าน — ทั้ง 24 ตัวเป็นค่าจากรายการตายตัว ไม่มีตัวไหนรับ free text |
| บัญชีฟรีลงได้ **50 มิติ + 50 เมตริก** | 🟢 ผ่าน — ใช้ 24 + 7 = เหลือที่ว่างเยอะ |
| **ไม่ย้อนหลัง** (no backfill) | 🟢 ตรงกับที่เตือนไว้แล้ว |

⚠️ **ตัวที่เกือบพลาด**: `topic` ใน `kb_query` — ถ้ามันคือ *คำถามที่ผู้ใช้พิมพ์เอง* จะเป็นทั้ง
cardinality ระเบิด **และ** ข้อมูลส่วนบุคคลรั่ว · ตรวจ `src/pages/Knowledge.tsx:38-43` แล้ว 🟢
ค่าที่ส่งคือ **หมวดที่ผู้ใช้เลือกจาก dropdown** (`topic === 'all' ? ...`) ไม่ใช่คำถาม
(คำถามอยู่ในตัวแปร `query` ซึ่งไม่ถูกส่งออกไปไหน)

## ข้อควรรู้

- **ไม่ย้อนหลัง** — เก็บได้เฉพาะข้อมูลที่เข้ามาหลังวันที่สร้าง ⇒ ยิ่งช้ายิ่งเสีย
- **โควตา GA4 ฟรี** — มิติข้อมูล 50 ช่อง · เมตริก 50 ช่อง (เรามี 111 พารามิเตอร์ จึงต้องเลือก)
- **ช่องพารามิเตอร์เป็น dropdown ที่กรองได้** — พิมพ์ชื่อลงไปตรง ๆ เร็วกว่าเลื่อนหา
  ถ้าไม่เจอในรายการ = GA4 ยังไม่เคยเห็นค่านั้น แต่ **ยังสร้างได้** (พิมพ์ให้ครบแล้วกดเพิ่ม)
- **ตัวเลขใน GA4 ต่ำกว่าความจริงเสมอ** — `index.html:120` ปิด GA จนกว่าผู้ใช้จะกด "ยอมรับทั้งหมด"
  ⇒ ห้ามเอาไปเทียบกับ `landing_funnel` (first-party ของเรา) แล้วสรุปว่าตัวใดตัวหนึ่งพัง
