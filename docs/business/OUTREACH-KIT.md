# ชุดทักเครือข่าย 300 คน — จังหวะ ISO 9001:2026

> **เป้าหมาย:** เซ็นโครงการใหญ่ 4 ราย + ค่าตรวจสุขภาพ 6–10 ราย ภายใน 3 เดือน
> **จังหวะที่ใช้:** ISO 9001:2026 ประกาศใช้ **16 ก.ย. 2569** (อีก ~1 เดือน)

---

## ⏰ ทำไมนี่คือจังหวะที่ดีที่สุดในรอบ 10 ปี

| ข้อเท็จจริง | แหล่ง |
|---|---|
| ISO 9001:2026 เผยแพร่ **16 ก.ย. 2569** | ISO / BSI / TÜV |
| ช่วงเปลี่ยนผ่าน **3 ปี → ก.ย. 2572** | ใบรับรอง 2015 ยังใช้ได้ตลอดช่วงนี้ |
| หน่วยรับรองต้องใช้เวลา **9–12 เดือน** กว่าจะตรวจตามฉบับใหม่ได้ | ใบรับรอง 2026 ใบแรกคาดว่าไม่ก่อน **ส.ค. 2570** |
| เป็นการปรับแบบ**วิวัฒนาการ ไม่ใช่ปฏิวัติ** | โครงสร้างข้อเหมือนเดิม · เพิ่มพื้นที่บังคับใหม่ 3 เรื่อง · ปรับโครงสร้าง 1 ข้อ · มี Annex แนะแนวครั้งแรก |
| เน้นเพิ่ม | วัฒนธรรมคุณภาพ · จริยธรรม · บทบาทผู้นำ |

**ทุกบริษัทที่ได้ ISO 9001 ในไทย มีเหตุผลที่จะคุยเรื่องนี้ — พร้อมกันทั้งตลาด ในเดือนเดียวกัน**

---

## 🎯 ท่าที่ต้องใช้ — และท่าที่ห้ามใช้

**ภายใน 34 วันข้างหน้า ที่ปรึกษาเกือบทุกเจ้าจะส่งข้อความแนวเดียวกันหมด:**
> *"มาตรฐานเปลี่ยนแล้ว! รีบติดต่อด่วน ไม่งั้นใบรับรองมีปัญหา"*

**ซึ่งไม่จริง** — ใบรับรองปัจจุบันใช้ได้ถึง ก.ย. 2572 และหน่วยรับรองยังตรวจฉบับใหม่ไม่ได้จนถึงปี 2570

### ท่าของเรา: เป็นคนที่บอกว่า "ยังไม่ต้องรีบ"

```
❌ "มาตรฐานเปลี่ยน รีบเปลี่ยนก่อนสาย"
✅ "มาตรฐานจะเปลี่ยน 16 ก.ย. แต่ยังไม่ต้องรีบ — ผมสรุปให้ว่ากระทบอะไรบ้าง"
```

**ทำไมท่านี้ชนะ:** ในเดือนที่ทุกคนโดนขู่จากทุกทาง คนที่บอกความจริงว่า *"ใจเย็นได้"*
คือคนเดียวที่ดูน่าเชื่อถือ — และเป็นคนที่เขาจะโทรหาตอนพร้อมจริง

**นี่ไม่ใช่กลยุทธ์ มันคือความจริง** และมันบังเอิญเป็นกลยุทธ์ที่ดีที่สุดด้วย

## 📋 แบ่งเครือข่าย 300 คนเป็น 4 กลุ่ม

| กลุ่ม | ใคร | ประมาณ | เป้าหมาย |
|---|---|---|---|
| **A** | เคยเป็นลูกค้า ทำงานด้วยแล้ว | ? | ปิดง่ายสุด — เริ่มที่นี่ |
| **B** | เคยคุยเรื่องงาน แต่ไม่ได้ทำ | ? | มีบริบทอยู่แล้ว |
| **C** | รู้จักในวงการ ไม่เคยคุยเรื่องงาน | ? | ให้ก่อน ไม่ขอ |
| **D** | เพื่อนร่วมงานเก่า/ลูกน้องเก่า ที่ตอนนี้อยู่บริษัทอื่น | ? | มักเป็นผู้แนะนำที่ดีที่สุด |

> ⚠️ **ทักกลุ่ม A ก่อนเสมอ วันละไม่เกิน 10 คน** — ไม่ใช่เพราะกลัวสแปม
> แต่เพราะถ้าตอบกลับมาพร้อมกัน 50 คน คุณจะรับไม่ไหวและตอบช้า ซึ่งแย่กว่าไม่ทัก

## 💬 สคริปต์ที่ 1 — กลุ่ม A (เคยเป็นลูกค้า)

**ส่งทางไลน์ · ห้ามยาวกว่านี้**

```
สวัสดีครับคุณ[ชื่อ] สบายดีไหมครับ

พอดีมีเรื่องอยากแจ้งให้ทราบก่อน — ISO 9001 จะออกฉบับใหม่
วันที่ 16 กันยายนนี้ครับ

ข่าวดีคือ ยังไม่ต้องรีบทำอะไร ใบรับรองปัจจุบันใช้ได้ถึงปี 2572
และหน่วยรับรองเองยังตรวจฉบับใหม่ไม่ได้จนถึงปีหน้า

แต่มี 3 เรื่องที่เพิ่มเข้ามาใหม่ ซึ่งถ้ารู้ไว้ก่อนจะเตรียมได้สบายกว่าเยอะ
ผมสรุปไว้ให้แล้วครับ เดี๋ยวส่งให้

ไม่ต้องตอบก็ได้นะครับ แค่อยากให้รู้ไว้
```

**หลักที่ใช้:**
- ไม่ขออะไรเลยแม้แต่อย่างเดียว
- ให้ข้อมูลที่**ลดความกังวล** ไม่ใช่เพิ่ม
- ปิดท้ายด้วย "ไม่ต้องตอบก็ได้" — คนที่ตอบคือคนที่สนใจจริง

**ถ้าเขาตอบกลับ → สคริปต์ที่ 3**

## 💬 สคริปต์ที่ 2 — กลุ่ม B, C, D

```
สวัสดีครับคุณ[ชื่อ] ไม่ได้คุยกันนานเลยครับ สบายดีนะครับ

พอดีช่วงนี้ผมรวบรวมเรื่อง ISO 9001 ฉบับใหม่ที่จะออก 16 กันยายนนี้
เลยนึกถึงคุณ[ชื่อ] เพราะน่าจะเกี่ยวกับที่[บริษัท]ทำอยู่

สรุปสั้น ๆ คือยังไม่ต้องรีบครับ ใบรับรองเดิมใช้ได้ถึงปี 2572
แต่มีของใหม่ 3 เรื่องที่ควรรู้ไว้ก่อน

ถ้าสนใจผมส่งสรุปให้อ่านได้ครับ ไม่มีอะไรต้องกรอก
```

**สำหรับกลุ่ม D เพิ่มบรรทัดนี้ท้ายสุด:**
```
ถ้ามีใครในทีมที่ดูแลเรื่องนี้อยู่ ฝากส่งต่อให้ได้เลยนะครับ
```

## 💬 สคริปต์ที่ 3 — เมื่อเขาตอบกลับ (จุดที่แปลงเป็นเงิน)

**อย่ารีบเสนอราคา ให้ถามก่อน 1 คำถาม**

```
ดีเลยครับ เดี๋ยวผมส่งให้

ขอถามอย่างเดียวครับ ตอนนี้ระบบที่[บริษัท]
มีคนดูแลเต็มตัวอยู่ไหม หรือฝากไว้กับใครคนหนึ่งที่ทำหลายหน้าที่?
```

**คำตอบบอกทุกอย่าง:**

| เขาตอบว่า | แปลว่า | ทำต่อ |
|---|---|---|
| "มีคนดูแลอยู่" | ระบบยังเดินอยู่ | เสนอ **ค่าตรวจสุขภาพ ฿39,000** |
| "ฝากไว้กับ[ชื่อ] ที่ทำหลายอย่าง" | ระบบเปราะ · เจ้าของรู้ตัว | เสนอ **ตรวจสุขภาพ** แล้วต่อโครงการเต็ม |
| "คนที่ทำลาออกไปแล้ว" | ⭐ **ลูกค้าที่ดีที่สุด** | เสนอ **โครงการเต็ม ฿200,000** ได้เลย |
| "ยังไม่ได้ทำ ISO" | ไม่ใช่กลุ่มนี้ | ให้สรุปไป จบอย่างดี · ขอให้ช่วยแนะนำต่อ |

## 💬 สคริปต์ที่ 4 — เสนอค่าตรวจสุขภาพ

```
จากที่คุยกัน ผมว่าน่าจะเริ่มจากตรวจสุขภาพระบบก่อนครับ

ผมเข้าไปดู 2-3 วัน แล้วออกรายงานให้ว่า
• เทียบกับมาตรฐานแล้วขาดอะไรบ้าง เป็นข้อ ๆ
• อะไรต้องแก้ก่อน-หลัง เพราะอะไร
• ถ้าจะทำให้ครบ ใช้เวลาและงบประมาณเท่าไร

ค่าตรวจ 39,000 บาทครับ

ได้รายงานไปแล้วจะทำเองต่อ หรือหาคนอื่นทำก็ได้ ไม่ผูกมัดอะไร
แต่ถ้าให้ผมทำต่อภายใน 60 วัน หักค่าตรวจนี้ออกจากค่าโครงการให้เลยครับ
```

**จุดสำคัญคือประโยคสุดท้าย** — "จะหาคนอื่นทำก็ได้" ทำให้เขากล้าตกลง เพราะไม่รู้สึกว่ากำลังถูกล็อก
และคนที่ได้รายงานไปแล้วเกือบทั้งหมดจะกลับมาหาคนที่เขียนรายงานนั้น

## 📅 แผน 34 วันก่อน 16 ก.ย.

| ช่วง | ทำอะไร | เป้า |
|---|---|---|
| **สัปดาห์นี้** | เขียนสรุป ISO 9001:2026 ให้จบ (2–3 หน้า) | มีของให้ส่ง |
| | ทักกลุ่ม A วันละ 10 คน | ทัก 50 คน |
| **สัปดาห์ 2** | ตอบคนที่ตอบกลับ · ใช้สคริปต์ 3 | คุยจริง 10 ราย |
| | ทักกลุ่ม B, D | ทักเพิ่ม 60 คน |
| **สัปดาห์ 3** | เสนอค่าตรวจสุขภาพ | เสนอ 8 ราย · ปิด 3–4 |
| **สัปดาห์ 4** | ตรวจสุขภาพรายแรก · ทักกลุ่ม C | เริ่มงานจริง |
| **16 ก.ย.** | วันประกาศใช้ — โพสต์สรุปสาธารณะ | คนที่ยังไม่ตอบจะนึกถึง |

**ตัวเลขที่ต้องได้: ทัก 110 คน → ตอบ 30 → คุยจริง 12 → เสนอ 8 → ปิด 4**

## ⚠️ กฎที่ห้ามฝ่าฝืน

- **ห้ามส่งพร้อมกันทีเดียว 300 คน** — รับไม่ไหว และตอบช้าแย่กว่าไม่ทัก
- **ห้ามใช้ความกลัว** — "ใบรับรองจะมีปัญหา" ไม่จริง และคนในวงการรู้
- **ห้ามส่งใบเสนอราคาก่อนถามคำถามในสคริปต์ 3** — ราคาที่มาก่อนบริบท คือราคาที่โดนต่อ
- **ห้ามลดราคาเมื่อโดนต่อ** — ให้ลดขอบเขตงานแทน (เช่น ตัดการนำเสนอผู้บริหารออก)
- **คนที่ไม่ตอบ ไม่ต้องตามซ้ำเกิน 1 ครั้ง** — เครือข่าย 25 ปีมีค่ากว่าดีลเดียว
