# สมุดบันทึกความผิดพลาด → กลไกที่เหลือไว้

> กติกา (จาก skill [`growth-mindset`](../.claude/skills/growth-mindset/SKILL.md)):
> **ทุกความผิดพลาดต้องเหลือ "กลไก" ไม่ใช่ "คำขอโทษ"**
> คำขอโทษหายไปเมื่อปิดแชท · เทสต์อยู่ตลอดไป
>
> ไฟล์นี้คือหลักฐานว่าระบบแข็งแรงขึ้นจริงหรือไม่ — ถ้าคอลัมน์ "กลไก" ว่าง แปลว่ายังไม่ได้เรียนรู้อะไร

## วิธีเพิ่มรายการ

เมื่อทำผิด (ไม่ว่าใครเป็นคนจับได้) ให้เพิ่มแถวใหม่ **พร้อมกับ commit ที่มีกลไกจริง**
ห้ามเพิ่มแถวโดยที่ยังไม่มีกลไก — แถวที่ไม่มีกลไกคือคำขอโทษที่แต่งตัวเป็นเอกสาร

## สรุปกลไกที่มีอยู่ตอนนี้ (จากความผิดพลาดจริง)

**เทสต์ที่มีอยู่เพราะเคยพลาด** — ไม่ใช่เทสต์ที่เขียนตามตำรา:

| กลไก | กันอะไร |
|---|---|
| `funnelCaveats` / `MIN_SAMPLE` | สรุปจากกลุ่มตัวอย่างเล็กเกินไป |
| `verdictOf` → `netLoss` | ขึ้นป้ายบวกทั้งที่ธุรกิจขาดทุน |
| `Insight` type (calc / question / action — **ไม่มี `fact`**) | AI พ่นสถิติตลาดที่ไม่มีแหล่งให้คนแปลกหน้าดู |
| เทสต์ banned-words (`productQuickCheck` · `pricingAnalysis`) | คำอ้างอิงสถิติที่เราไม่มีแหล่ง |
| เทสต์ payload ไม่มีชื่อสินค้า | ข้อมูลที่อาจเป็น PII หลุดขึ้น server |
| `checkupReportDrift.test.ts` | repo กับ Edge Function บน production ไม่ตรงกัน |
| เทสต์ `TRIAL_ROADMAP` ชี้หน้าที่มีจริง | สัญญาบนหน้าเว็บถึงสิ่งที่ยังไม่ได้สร้าง |
| เทสต์ `ISO_EARLY_NOTE` | เขียนคอนเทนต์ผิดหลักการ `iso-from-day-one` |
| เทสต์ `PROCESS_TEMPLATES` ครบทุกข้อกำหนด ไม่ซ้ำ | โครงตั้งต้นตกหล่นข้อกำหนดโดยไม่มีใครรู้ |
| `concernsTrustworthy` / `MIN_CONCERN_SAMPLE` | อ่านอันดับความกังวลจากคนไม่กี่คน |
| `landingClaims.test.ts` (ใหม่ 16 ส.ค.) | คำสัญญาที่ระบบทำไม่ได้หลุดขึ้นหน้าสาธารณะ — สแกนทั้ง lib และไฟล์ .tsx · **ทดสอบแล้วว่าแดงจริงเมื่อใส่คำต้องห้ามเข้าไป** |

**จำนวนเทสต์ทั้งระบบ:** 1,388 (ณ 16 ส.ค. 2569)
