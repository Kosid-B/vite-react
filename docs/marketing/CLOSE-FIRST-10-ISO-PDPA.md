# แผนปิด 10 ลูกค้าจ่ายเงินแรก — หัวหอก ISO 9001 / PDPA / มอก. (30 วัน)

> **ทำไมแผนนี้ก่อนอย่างอื่น:** market sizing (MARKET-SIZING-2026.md) สรุปว่า TAM ล้นอยู่แล้ว
> คอขวดจริง = **distribution/activation** (ตอนนี้ 1 workspace, 0 รายได้) เป้าเดียวที่มีค่าที่สุด =
> **พิสูจน์ว่า SAM แปลงเป็นเงินได้จริง** ด้วยลูกค้าจ่ายเงิน 10 ราย จากฐานที่ B.Training มี distribution + เครดิตอยู่แล้ว
>
> เอกสารนี้ = playbook ลงมือจริง (คู่กับ CONCIERGE-SEED-CHECKLIST.md + OUTREACH-20-LEADS-SCRIPTS.md)

## 0. ทำไมต้องหัวหอก ISO/PDPA (ไม่ใช่ Gen Z / แม่ค้า)
| | ISO/PDPA (หัวหอก) | รายเล็ก/มือใหม่ |
|---|---|---|
| Distribution | **มีอยู่แล้ว** — ฐานลูกค้า B.Training 20 ปี | ต้องหา cold |
| เครดิต/ความเชื่อใจ | **สูงมาก** (รู้จักตัวจริง) | ต้องสร้างใหม่ |
| WTP | จ่ายที่ปรึกษาหลักหมื่น–แสนอยู่แล้ว | ต่ำ |
| ตรงฟีเจอร์ | Privacy Notice / Compliance Check / Knowledge (สร้างแล้ว) | ต้อง onboard เยอะ |
| **สรุป** | **แปลงเป็นเงินเร็วสุด** | เก็บไว้เฟสหลัง (volume play) |

> พลังงานทั้งหมด 30 วันนี้ ทุ่มที่คนที่ **รับสายเราแล้วไว้ใจอยู่แล้ว**

## 1. เป้าเชิงตัวเลข (30 วัน)
| Metric | เป้า | ที่มา |
|---|---|---|
| รายชื่อจากฐาน B.Training | **30 ราย** | คัดจาก CRM/สมุดลูกค้าเดิม |
| ติดต่อได้ + คุย | 20 ราย | ~66% |
| นัด demo/ให้ลอง (concierge) | 12 ราย | ~60% ของที่คุย |
| **ลูกค้าจ่ายเงิน** | **10 ราย** | ปิดจาก demo |
| MRR ประมาณการ | **฿6,000–15,000/เดือน** | คละ Starter–Growth |

Funnel เป้า: 30 → 20 → 12 → **10 จ่าย** (ถ้าปิดได้แค่ 5 ก็ยังพิสูจน์ตลาดแล้ว = ก้าวสำคัญ)

## 2. คัดรายชื่อ 30 ราย — เรียงตามความน่าปิด
กรอกลง `outreach-tracker.csv` (มีอยู่แล้วใน docs/marketing/) — คอลัมน์: ชื่อ · บริษัท · เบอร์/LINE · segment · งานที่เคยทำ · สถานะ · นัดวันไหน

**ลำดับความสำคัญ (โทรกลุ่ม A ก่อน):**
- **A — ร้อนสุด (10 ราย):** ลูกค้าที่ **กำลังทำ/ต่ออายุ ISO 9001 ปีนี้** หรือ **เพิ่งถาม PDPA** → มี pain สด ใช้ได้พรุ่งนี้
- **B — อุ่น (10 ราย):** ลูกค้าเก่าที่สนิท ไว้ใจ ขอให้ช่วยลองใช้ + ติชมตรง ๆ
- **C — เย็น (10 ราย):** ลูกค้าที่หายไปนาน / โรงงานที่มี มอก. → reactivate ด้วยของใหม่

## 3. ข้อเสนอ (Offer) — เลือก 1 ใน 2

### 3.1 Concierge Free Trial (default — ลด friction สูงสุด)
> "ใช้ฟรี 15 วันเต็ม **ผมตั้งระบบให้เลย** (ไม่ต้องยุ่งยาก) — ช่วยงาน ISO/PDPA ที่คุณทำอยู่ให้เร็วขึ้น
> แลกกับ feedback 15 นาที · ถ้าชอบค่อยว่ากันเรื่องแพ็ก"

### 3.2 ISO Readiness Pilot (สำหรับกลุ่ม A ที่ร้อนจัด — ปิดการขายเลย)
> "Pilot ฿1,990 ครั้งเดียว — ประเมินความพร้อม ISO ก่อน audit + ใช้ระบบเต็ม 1 เดือน"
> (มี slot ใน config: `PAYMENT.stripePaymentLinkPilot` + `pilotPrice` — เปิดใช้เมื่อพร้อม)

**หลักการปิด:** อย่าเริ่มด้วยราคา เริ่มด้วย **"ช่วยงานที่คุณทำอยู่แล้ว ให้เร็วขึ้น"** แล้วให้เห็นคุณค่าใน 5 นาที

## 4. Scripts (คัดลอกใช้ได้ทันที)

### 4.1 LINE / ข้อความแรก (กลุ่ม A — มี pain ISO/PDPA สด)
```
สวัสดีครับคุณ[ชื่อ] — [ชื่อเรา] จาก B.Training ครับ
พอดีเราเพิ่งทำเครื่องมือ AI ช่วยงาน ISO 9001 / PDPA (จากประสบการณ์ที่ปรึกษา 20 ปี)
— ช่วยร่าง Privacy Notice, ตรวจความพร้อมเอกสาร ISO ก่อน audit, ตอบข้อกำหนดได้ทันที

เห็นว่าคุณ[ชื่อ]กำลังทำ[ISO/PDPA]อยู่ อยากให้ลองใช้ฟรี ผมตั้งระบบให้เลย
ขอโชว์ 15 นาที (โทร/LINE ก็ได้) สะดวกวันไหนดีครับ?
```

### 4.2 โทรศัพท์ (opening 20 วินาที)
```
"คุณ[ชื่อ]ครับ [ชื่อเรา] B.Training นะครับ — ไม่ได้มาขายของ
คือเราทำ AI ช่วยงาน ISO/PDPA ที่คุณทำอยู่ให้เร็วขึ้น อยากขอ 15 นาทีโชว์ให้ดู
ถ้าไม่มีประโยชน์จริงบอกได้เลยครับ ผมอยากได้ feedback ตรง ๆ มากกว่า"
```

### 4.3 Follow-up (ยังไม่ตอบ — ส่งวันที่ 3)
```
คุณ[ชื่อ]ครับ ส่งตัวอย่างให้ดูเลยดีกว่า 👇
[ลิงก์: Privacy Notice ที่ AI ร่างให้ใน 2 นาที / Readiness Score ตัวอย่าง]
ถ้าสนใจให้ผมตั้งให้ใช้กับงานจริงของคุณ ทักมาได้เลยครับ
```

### 4.4 หลัง demo → ปิด
```
"ที่เห็นเมื่อกี้ ระบบร่าง/ตรวจให้ในไม่กี่นาที เทียบกับที่ทีมทำมือหลายวัน
ลองใช้ฟรี 15 วันก่อนได้เลย ผมตั้ง workspace ให้แล้ว [ส่งลิงก์]
ถ้าโอเค แพ็ก Starter ฿390/เดือน หรือ Growth ฿1,490 (มีตรวจ ISO เชิงลึก) — จ่าย PromptPay อัปสลิป เปิดใช้ทันที"
```

## 5. วิธี onboard (เลี่ยงจุดตัน signup — สำคัญ!)
> จุดตายเดิม = ลูกค้าติดหน้า "ยืนยันอีเมล" แล้วหายไป (ดู FIRST-10-USERS.md)

1. **เราสร้าง workspace ให้เลย** (สมัครแทน หรือนั่งทำด้วยกันผ่านหน้าจอ) — ไม่ปล่อยให้ติดหน้ายืนยันอีเมลเอง
   - ⚠️ external task: ปิด "Confirm email" ใน Supabase Auth ให้ signup เข้าทันที
2. โชว์ **1 use case ที่ตรงงานเขาที่สุด** ให้เห็นคุณค่าใน 5 นาที:
   - ISO → หน้า **Compliance Check** (ตรวจ 28 ข้อกำหนด ISO 9001 → Readiness Score)
   - PDPA → หน้า **Privacy Notice** (ร่าง Privacy Notice/SOP อัตโนมัติ)
   - ทั่วไป → หน้า **Knowledge** (ถาม-ตอบข้อกำหนด ISO/PDPA ทันที)
3. **ทิ้งงานจริงไว้ในบัญชี** (มีของให้กลับมาดู) + นัด follow-up
4. จ่ายเงิน → **PromptPay + อัปสลิป → เปิดแพ็กทันที** (PLG ที่เพิ่งทำ — ไม่ต้องรอ admin)
