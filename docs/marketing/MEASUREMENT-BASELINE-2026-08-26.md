## ③ Analyze — สาเหตุราก (1 ข้อ)

**เวลาของบล็อกถูกบวกเข้าบัญชี "เฉพาะตอนบล็อกออกจากจอ" (`markSectionExit`)**

⇒ บล็อกที่อยู่ในจอ **ตลอดการเยี่ยมชม** จะถูกบันทึกก็ต่อเมื่อมี exit event สะอาด ๆ ตอนออกจากหน้า
และคนที่ **ไม่เลื่อนเลย** คือ **80 จาก 93 คน** — คนกลุ่มใหญ่ที่สุดของเรา คือกลุ่มที่ระบบมองไม่เห็น

🔴 หลักฐานว่าไม่ใช่ "ท่อส่งข้อมูลพัง": **`max_dwell` ของคนกลุ่มเดียวกันบันทึกได้ปกติ**
(dwell ส่งผ่าน `scheduleFlush` ระหว่างทาง · section ส่งตอน exit เท่านั้น)

⚠️ บทเรียนที่กว้างกว่าตัวบั๊ก: **exit event บนมือถือเชื่อถือไม่ได้**
ระบบฆ่าแท็บเบื้องหลังได้โดยไม่ยิงอะไรเลย ⇒ **ห้ามออกแบบให้ข้อมูลทั้งก้อนขึ้นกับ event ที่อาจไม่เกิด**
