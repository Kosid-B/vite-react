## Brand Brief คืออะไร (และทำไมต้องมี)

```
   ┌─────────────────┐
   │ บริษัท          │
   │ ปัญหา           │  ← Brand Brief
   │ ความต้องการ      │
   │ ผลลัพธ์         │
   └────────┬────────┘
            ↓
  คน  →  PROMPT  →  AI
   └───────────────────┘   (ผลลัพธ์วนกลับมาให้คนตรวจ)
```

AI ไม่รู้จักธุรกิจเรา มันรู้แค่สิ่งที่เราบอกในแต่ละครั้ง
**ถ้าไม่มี brief** → ทุกครั้งที่สั่งงาน AI จะได้คำตอบที่ "ทั่วไป" และคนละโทนกันทุกครั้ง
**ถ้ามี brief** → AI เขียนเหมือนคนในทีมที่รู้ว่าเราขายใคร ห้ามพูดอะไร และอะไรที่เรายังทำไม่ได้

## 🔴 ช่องที่ Brand Brief ทั่วไปไม่มี — "สถานะจริงตอนนี้"

brief ที่เล่าแต่ภาพฝัน จะทำให้ AI เขียนคอนเทนต์ที่อ้างการยอมรับที่เรายังไม่มี
เช่น *"ลูกค้าหลายร้อยราย"* — **เป็นคำโกหกที่ตรวจจับยากที่สุด เพราะฟังดูปกติมาก**

brief ของเราจึงบังคับใส่ว่า: ยังไม่มีลูกค้าจ่ายเงินจริงสักราย · ผู้เข้าชมสะสมอยู่ในหลักสิบ
⇒ AI ที่ได้ brief นี้ จะขายด้วย **"สิ่งที่ระบบทำได้"** แทน **"มีคนใช้เยอะแค่ไหน"**

⚠️ ตัวเลขในช่องนี้ต้องอัปเดตเมื่อของจริงเปลี่ยน — อ่านสดได้จาก `stageFit.ts` + `payingCustomerCount()`

## วิธีใช้

**ในโค้ด** — แปะหน้า prompt ที่ AI ต้องพูดแทนแบรนด์:
```ts
import { brandBriefBlock } from './brandBrief';
const prompt = [brandBriefBlock({ forPublicCopy: true }), '', '## งานที่สั่ง ...'].join('\n');
```
`forPublicCopy: true` = แนบ "คำที่ห้ามปรากฏ" ไปด้วย (ใช้เมื่อจะเขียนข้อความที่คนนอกเห็น)

**ใช้กับ AI ตัวอื่น (ChatGPT / Gemini / ฯลฯ)** — สั่งให้ผมพิมพ์ brief ออกมาแล้วก๊อปไปวางหน้าคำสั่ง

**ตรวจก่อนปล่อยคอนเทนต์**:
```ts
import { violatesBrand } from './brandBrief';
violatesBrand(draft);   // คืนรายการคำต้องห้ามที่เจอ · ว่าง = ผ่าน
```
