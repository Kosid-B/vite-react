## 🔴 ทำไมต้องมีไฟล์นี้

โค้ดฝั่ง utm **สร้างเสร็จและทำงานได้แล้ว** (ยืนยัน: 19–20 ส.ค. มีแถวที่ติด utm เข้ามาจริง)

⇒ นี่ไม่ใช่ปัญหาโค้ด **เป็นปัญหาว่าตอนโพสต์ไม่มีใครเปิดดูว่าต้องพิมพ์อะไร**
⇒ ไฟล์นี้แก้ตรงนั้น: **ไม่ต้องคิด ไม่ต้องจำ คัดลอกไปวาง**

## วิธีอ่าน: `ceoaithailand.org/<เรื่อง>/<แพลตฟอร์ม>`

ตัวย่อท้ายบอกว่ามาจากไหน — **ขาดตัวนี้ = รายงานจะบอกไม่ได้ว่าใครพามา**

| ตัวย่อ | แปลว่า | ใช้ตรงไหน |
|---|---|---|
| `yt` | youtube / shorts | คำบรรยาย Shorts |
| `ytc` | youtube / comment | **คอมเมนต์ปักหมุดใต้คลิป** |
| `tt` | tiktok / bio | ลิงก์ในไบโอ TikTok |
| `ttc` | tiktok / comment | คอมเมนต์ใต้คลิป TikTok |
| `fb` | facebook / social | โพสต์/ไบโอเพจ |
| `fbc` | facebook / comment | **คอมเมนต์ปักหมุดใต้ Reels** |
| `ig` | instagram / story | Link sticker ใน Story |
| `line` | line / message | ส่งในไลน์/กลุ่มไลน์ |
| `li` | linkedin / social | โพสต์ LinkedIn |
| `qr` | offline / qr | QR บนนามบัตร/ป้าย |

## แยกคลิปในช่วงเดียวกัน (ไม่บังคับ แต่ทำแล้วอ่านผลละเอียดขึ้น)

เติม `?c=` ต่อท้ายเพื่อบอกว่าเป็นคลิปไหน — เช่นคลิปที่ 1 ของช่วง:

```
ceoaithailand.org/ทุน/ytc?c=1a
```

⇒ รายงานจะแยกได้ว่า **คลิปไหนในช่วงนั้นพาคนมาได้** ไม่ใช่รู้แค่ว่าช่วงนั้นได้กี่คน

## 🚫 สิ่งที่ห้ามทำ

| ห้าม | ทำไม |
|---|---|
| พิมพ์ `ceoaithailand.org` เฉย ๆ | ไม่ติดแท็ก ⇒ กลายเป็น `direct` ปนกับคนอื่นทั้งหมด **ตลอดไป กู้คืนไม่ได้** |
| ลืมตัวย่อท้าย (`/ทุน` เฉย ๆ) | รู้ว่าคอนเทนต์ไหน แต่ไม่รู้ว่าแพลตฟอร์มไหน |
| **วางลิงก์ในโพสต์ฟีด Facebook** | วัดจริง: Reels 14,500 วิว · โพสต์ที่มีลิงก์วันเดียวกัน **0 วิว** ⇒ ให้อยู่ในคอมเมนต์ปักหมุด |
| ใส่ลิงก์ในชื่อคลิป YouTube | กดไม่ได้ + กินที่ hook |
| สลับเรื่องรายวัน | ไบโอมีได้ทีละอัน ⇒ คลิปเก่าจะชี้ผิดหน้าทั้งหมด (ล็อก 1 เรื่อง/2 สัปดาห์) |

## เช็กก่อนกดโพสต์ทุกครั้ง (30 วินาที)

1. เปิดลิงก์ที่จะวาง **จากมือถือจริง** 1 ครั้ง — เข้าถูกหน้าไหม
2. ตัวย่อแพลตฟอร์มตรงกับที่จะวางจริงไหม (คอมเมนต์ = `ytc`/`fbc`/`ttc` ไม่ใช่ `yt`/`fb`/`tt`)
3. ถ้าเป็น TikTok/IG — **ไบโอถูกสลับมาเป็นเรื่องของช่วงนี้แล้วหรือยัง**
4. ปิดคอนเทนต์ด้วย **คำถาม** ไม่ใช่ลิงก์ (ลิงก์ก่อน = โฆษณา)
