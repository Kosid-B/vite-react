4. กติกาเหล็ก: **อย่าโชว์เกิน 1 หน้าหลัก** ต่อ 1 pain — ลึก ไม่กว้าง

## 2. Track A — ลูกค้า PDPA (แม่เหล็กแรงสุด · WTP Starter–Growth)

**Pain:** ต้องมี Privacy Notice / SOP / ตอบข้อสงสัยข้อกำหนด — เดิมจ้างที่ปรึกษา/ทำมือ

**Click-path:**
1. Sidebar → **`ตัวช่วย PDPA`**
2. กรอกข้อมูลจริงของลูกค้า (ประเภทธุรกิจ + ข้อมูลที่เก็บ เช่น "ชื่อ-เบอร์-ที่อยู่ลูกค้า สำหรับจัดส่ง")
3. กด generate → **Privacy Notice ร่างเสร็จใน ~2 นาที** (ภาษาไทย พร้อมใช้)
4. ชี้ให้ดู: "นี่แก้เป็นของบริษัทคุณได้เลย — เอกสารที่ audit/ลูกค้าขอ มีทันที"
5. (ถ้ามีเวลา) → **`คลังความรู้ ISO/PDPA`** พิมพ์คำถามจริงที่เขาสงสัย เช่น "ต้องขอ consent ยังไงถึงถูกกฎหมาย" → ตอบทันที

**ประโยคเชื่อม:** "PDPC ออกกรอบ certification ใหม่ (มิ.ย. 2569) แล้ว — ลูกค้าเริ่มถามหาเอกสารพวกนี้ คุณมีพร้อมก่อนคู่แข่ง"

---

## 3. Track B — ลูกค้า ISO 9001 / มอก. (WTP สูงสุด · Growth–Scale)

**Pain:** เตรียมเอกสารก่อน audit / ต่ออายุ cert — เอกสารเยอะ ตรวจเองช้า

**Click-path:**
1. Sidebar → **`AI ตรวจเอกสาร ISO/มอก.`**
2. วางเอกสาร/ขั้นตอนจริงของลูกค้า (เช่น procedure ที่เขามี) → AI ตรวจเทียบข้อกำหนด → ชี้จุดขาด
3. หรือ → **`ISO 9001:2015 QMS`** โชว์ **Readiness Score** ครบ 28 ข้อกำหนด (ข้อ 4–10) + ตารางวางแผน internal audit
4. ชี้: "ก่อนเรียก auditor คุณรู้ล่วงหน้าว่าติดตรงไหน — ลดความเสี่ยงตก audit"
5. → **`คลังความรู้ ISO/PDPA`** ถามข้อกำหนดที่ทีมมักสงสัย → ตอบพร้อมอ้างอิงข้อ

**ประโยคเชื่อม:** "รองรับ SGS, Bureau Veritas, TÜV SÜD — Readiness Score ใช้กับหน่วยรับรองไหนก็ได้"

## 4. กฎการปิด (ปิดใน demo เลย อย่าปล่อยให้ "คิดดูก่อน" ลอย)
- **ตั้ง workspace ให้เสร็จในสาย** — "ผมสร้างให้แล้วนะครับ คุณเข้าลองได้เลยวันนี้"
- ให้มี **ของค้างในมือ** — เอกสารที่เพิ่ง generate อยู่ในบัญชีเขาแล้ว (เสียดายถ้าไม่ใช้ต่อ)
- เสนอราคาแบบเทียบ: "Starter ฿390/เดือน = ถูกกว่าจ้างร่างเอกสาร 1 ครั้งหลายเท่า"
- ปิดการจ่าย: "จ่าย PromptPay สแกน QR ในหน้าแพ็กเกจ อัปสลิป **เปิดใช้ทันที**" (PLG — ไม่ต้องรอใคร)
- ถ้ายังไม่พร้อมจ่าย → "ลองฟรี 15 วันก่อน ผมโทรกลับวัน [ระบุ]" + ลง tracker
