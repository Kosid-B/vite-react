## ✅ ทำใน CapCut (ทุกคลิป · ~5 นาที)
1. **นำเข้า** คลิปอัดหน้าจอแอป (เมือง/การเงิน/ประเมิน ISO) เป็นพื้นหลัง
2. **Text to Speech**: วางบทพากย์ → เสียงไทยผู้ชาย โทนมั่นใจ
3. **ข้อความ**: ก๊อปแต่ละบรรทัดวางบนจอตามจังหวะ (บรรทัดแรก = วิแรกเด้งทันที!) ตัวใหญ่ ขาว/เหลือง
4. **คำบรรยายอัตโนมัติ (Auto Captions)** → ตัวหนา (คนปิดเสียงอ่านได้)
5. **เพลง** Corporate/Upbeat เบา ~15%
6. **Export** 1080×1920 · 30fps
7. โพสต์ → ปักหมุดคอมเมนต์แรก + ตั้ง bio link (utm)
