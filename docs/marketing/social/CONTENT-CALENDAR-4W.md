## 🚨 ส่วนที่ต้องแก้ก่อนโพสต์ — เรียงตามความร้ายแรง

### 1. ❌ "จ่ายค่าธรรมเนียม 3% เมื่อปิดดีล" — **ไม่ใช่โมเดลราคาของเรา**

| | |
|---|---|
| ร่างบอกว่า | ใช้ฟรี · จ่าย 3% เฉพาะเมื่อปิดดีลได้จริง |
| ความจริงในโค้ด | `marketplaceFees.ts` → `FEE.live = false` = **ไม่เก็บค่าธรรมเนียมเลย ฿0**<br>รายได้จริงมาจาก **ค่าสมาชิกรายเดือน** ฿790 / ฿1,490 / ฿5,900 |

**นี่คือจุดที่ร้ายแรงที่สุด** — โฆษณาว่า "ฟรี จ่ายแค่ 3% ตอนได้เงิน" แล้วคนสมัครมาเจอกำแพงค่าสมาชิก
= ความรู้สึกโดนหลอกตั้งแต่นาทีแรก · เสียทั้งลูกค้าและชื่อเสียง และแก้กลับยากมาก

ปรากฏใน **สัปดาห์ 3, สัปดาห์ 4, และข้อความปิดท้ายมาตรฐาน** → ต้องลบทุกจุด

### 2. ❌ "ที่ปรึกษา 20 ปี → ฟรี" — ทำลายทางที่จะไปถึง ฿200,000/เดือน

สัปดาห์ 4 เขียนว่า *"ที่ปรึกษาวางระบบมาตรฐาน 20 ปี → ฟรี"*

รายได้ ฿200,000/เดือนที่ตั้งเป้าไว้ มาจาก **งานที่ปรึกษา ISO/PDPA กับเครือข่าย 300 คน**
ถ้าประกาศต่อสาธารณะว่าความเชี่ยวชาญ 25 ปีของคุณ "ฟรี" — เวลาเสนอราคาโปรเจกต์จริงหลักแสน
ลูกค้าที่เคยเห็นโพสต์จะถามทันทีว่า *"ไม่ใช่บอกว่าฟรีเหรอ"*

**เขียนแบบนี้แทน:** ระบบนำ*วิธีคิด*ที่ได้จากงานที่ปรึกษา 25 ปีมาใส่ไว้ให้ใช้เอง —
ส่วนงานที่ต้องมีคนตรวจและรับรอง ยังเป็นงานที่ปรึกษาเหมือนเดิม (คนละของ คนละราคา)

### 5. ⚠️ สัปดาห์ 2 ล้ำเส้นจริยธรรมของเราเอง
*"อย่ารอถูกเลิกจ้าง"* + *"ลาออกมาทำธุรกิจ"* = ใช้ความกลัวตกงานผลักคนไปตัดสินใจเรื่องใหญ่
ขัดกับ skill `pain-gain-discovery` §E (ทำให้ปัญหาที่มีจริงชัดขึ้น = ถูก · เร่งด้วยความกลัว = ผิด)
และขัดกับตัวสินค้าเองที่สอนว่า **"ทดสอบก่อน ค่อยเสี่ยง"**

→ เขียนใหม่เป็น **"เริ่มโดยไม่ต้องลาออก"** ซึ่งจริงกว่า ปลอดภัยกว่า และตรงกับสิ่งที่ระบบทำได้จริง

```

• TDRI ประเมินว่าคนไทยราว 8.3 ล้านคนทำงานในอาชีพที่มีโอกาสถูกแทนที่ด้วย AI สูงกว่า 70%
```
