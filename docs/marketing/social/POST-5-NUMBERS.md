**ปลายทาง**: `ceoaithailand.org/ราคา` → `/calc` (เครื่องคำนวณจริง ฟรี ไม่ต้องสมัคร)

## ที่มา และสิ่งที่ **ไม่** ลอกมา

เจ้าของส่งภาพอ้างอิงมา (โพสต์ 100WEALTH) — เราลอก **รูปแบบ** แต่ไม่ลอก **วิธีสร้างความน่าเชื่อถือ**

| ภาพอ้างอิงทำ | เราทำแทนด้วย | เหตุผล |
|---|---|---|
| วางโลโก้สถาบันบนไดอะแกรม | ไม่มีตราสถาบันใด ๆ | ยืมแบรนด์คนอื่นมาเป็นอำนาจ = เสี่ยงเครื่องหมายการค้า + ผิดหลักโปรเจกต์ |
| **"ได้เกิน 200 ล้าน"** | เลขคณิตที่ผู้อ่าน**ตรวจเองได้** | ลูกค้าจ่ายจริงของเรา = **0 ราย** ⇒ `videoBrief.PROOF.banned` |
| *"จับอะไรก็เป็นธุรกิจได้หมด"* | *"คุณตอบได้กี่ข้อ?"* | สัญญาเหมารวมขัด Founder Mindset · คำถามสร้างความตึงโดยไม่ต้องโกหก |
| — | ✅ โครงหน้าตา: ไดอะแกรมบน + พาดหัวใหญ่ทับล่าง | นี่คือ**รูปแบบ** อ่านออกในฟีดมือถือ ลอกได้ |

## 🔒 ตัวเลขในภาพผูกกับโค้ดจริง

ตัวอย่างในภาพ: **ราคา 150 · ทุน 90 · 300 ชิ้น/เดือน**

| ในภาพ | มาจาก |
|---|---|
| กำไรต่อหน่วย `150 − 90 = 60` | นิยาม m ใน `pricingAnalysis` |
| ขึ้นราคา 10% → **เสียลูกค้าได้ 20%** | `priceScenario(input, 10).breakEvenVolumePct` |
| ลดราคา 10% → **ต้องขายเพิ่ม 33%** | `priceScenario(input, -10).breakEvenVolumePct` = −33.33 |

🔴 `socialPostContract.test.ts` อ่าน **สคริปต์ตัวจริง** แล้วเทียบกับผลของฟังก์ชัน
⇒ **แก้สูตรแล้วไม่แก้ภาพ = แดงทันที** · ภาพโกหกโดยไม่มีใครรู้ไม่ได้
(ยืนยันแดงจริง 4 การกลายพันธุ์: แก้เลขให้เพี้ยน · ใส่ "200 ล้าน" · ยืมชื่อสถาบัน · ลิงก์ที่ไม่มีจริง)

## แคปชัน (ผ่าน `violatesBrand()` แล้ว = ไม่มีคำต้องห้าม)

```
ข้อ 3 กับ 4 คุณตอบได้ไหม?

ขึ้นราคา 10% — เสียลูกค้าได้กี่ % ก่อนกำไรจะหาย
ลดราคา 10% — ต้องขายเพิ่มกี่ % ถึงจะเท่าเดิม

สองข้อนี้ไม่ใช่การเดา เป็นเลขคณิตที่คำนวณได้จาก "ราคา" กับ "ต้นทุน" ของคุณเอง
ไม่ต้องรู้ข้อมูลตลาด ไม่ต้องรอใครมาบอก

ตัวอย่าง: ขาย 150 ทุน 90 (กำไรต่อหน่วย 60 บาท)
• ขึ้นเป็น 165 → เสียลูกค้าได้ถึง 20% กำไรรวมยังเท่าเดิม
• ลดเหลือ 135 → ต้องขายเพิ่ม 33% ถึงจะเท่าทุนเดิม

ตัวเลขของร้านคุณล่ะ ออกมาเท่าไหร่
ใส่ราคากับทุน แล้วได้คำตอบทันที ฟรี ไม่ต้องสมัคร
ceoaithailand.org/ราคา
```

⚠️ **คำถามมาก่อนลิงก์เสมอ** (`content-link-contract`) — ลิงก์ขึ้นก่อน = โฆษณา
