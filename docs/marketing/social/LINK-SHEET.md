## 🏷️ ต่อท้าย `?s=` เพื่อบอกว่ามาจากแพลตฟอร์มไหน

**URL ในภาพ** ใช้ตัวสั้นเปล่า ๆ (ให้คนพิมพ์ตาม) · **URL ในแคปชัน/คำอธิบาย** ต่อท้ายด้วย `?s=`
ไม่ต่อก็ยังใช้ได้ แค่จะรวมเป็นก้อน `social` แยกไม่ออกว่ามาจากที่ไหน

| ต่อท้าย | แพลตฟอร์ม | ตัวอย่างเต็ม |
|---|---|---|
| `?s=yt` | YouTube Shorts | `ceoaithailand.org/price?s=yt` |
| `?s=ytv` | YouTube คลิปยาว | `ceoaithailand.org/price?s=ytv` |
| `?s=tt` | TikTok (ไบโอ) | `ceoaithailand.org/sms?s=tt` |
| `?s=fb` | Facebook feed | `ceoaithailand.org/sms?s=fb` |
| `?s=ig` | Instagram Story | `ceoaithailand.org/tun?s=ig` |
| `?s=line` | LINE / กลุ่มไลน์ | `ceoaithailand.org/customer?s=line` |
| `?s=li` | LinkedIn | `ceoaithailand.org/plan?s=li` |
| `?s=qr` | QR ในนามบัตร/เอกสาร | `ceoaithailand.org/ai?s=qr` |

**แยกคลิปย่อยในเรื่องเดียวกัน** เติม `&c=` เข้าไป — ใช้ตอนทำ A/B (เวอร์ชัน A vs B)
```
ceoaithailand.org/price?s=yt&c=1a
ceoaithailand.org/price?s=yt&c=1b
```

> ค่าที่ไม่รู้จักจะตกกลับเป็น `social/organic` เอง — พิมพ์ผิดไม่พัง แค่เสียการแยกที่มา

## 📅 ปฏิทินสลับไบโอ — เปลี่ยนเดือนละ 2 ครั้ง ไม่ใช่วันละครั้ง

**ทำไม:** TikTok/Instagram มีลิงก์ไบโอได้ทีละอัน และอัลกอริทึมดันคลิปเก่าขึ้นมาใหม่ได้เสมอ
ถ้าสลับไบโอตามคลิปที่เพิ่งโพสต์ คนที่ดูคลิปเก่าวันนี้จะกดไปเจอเรื่องที่ไม่เกี่ยว = เสียไปทั้งหมด

**วิธีแก้:** ล็อกหนึ่งเรื่องต่อหนึ่งช่วง โพสต์เรื่องนั้นรวดทั้งช่วง แล้วค่อยสลับ

| ช่วง | เรื่องที่โพสต์ | ไบโอ TikTok | ไบโอ Instagram |
|---|---|---|---|
| **12–30 ส.ค. 69** | SMS ปลอม ⏰ *มีเส้นตาย* | `https://ceoaithailand.org/sms?s=tt` | `…/sms?s=ig` |
| 31 ส.ค.–14 ก.ย. | 🌴 **ราคาปาล์ม** ✅ *พิสูจน์แล้ว 781 วิว* | `…/palm?s=tt` | `…/palm?s=ig` |
| 15–28 ก.ย. | ต้นทุน / ตั้งราคา · ราคาอุปกรณ์ขึ้น | `…/price?s=tt` หรือ `…/pc?s=tt` | `…/price?s=ig` |
| 29 ก.ย.–12 ต.ค. | หาลูกค้า 10 คนแรก | `…/customer?s=tt` | `…/customer?s=ig` |
| 13–26 ต.ค. | เริ่มธุรกิจไม่มีทุน | `…/tun?s=tt` | `…/tun?s=ig` |
| 27 ต.ค.–9 พ.ย. | แผนธุรกิจ / ทำคนเดียว | `…/plan?s=tt` | `…/plan?s=ig` |
| 10–23 พ.ย. | ไม่ต้องเก่ง AI | `…/ai?s=tt` | `…/ai?s=ig` |

> **เรียงตามเส้นตาย ไม่ใช่ตามความชอบ** — SMS ปลอมมาก่อนเพราะมีวันหมดอายุจริง (30 ส.ค.)
> เรื่องที่ไม่มีเส้นตายเลื่อนได้โดยไม่เสียอะไร
>
> **แล้วทำไมปาล์มแซงขึ้นมาเป็นช่วงที่ 2?** เพราะเป็นเรื่องเดียวที่มี *หลักฐานว่าคนสนใจจริง*
> (คลิปได้ 781 วิวโดยยังไม่มีปลายทางให้กด) ส่วนเรื่องอื่นยังเป็นการเดาว่าจะติด
> **เรื่องที่พิสูจน์แล้วมาก่อนเรื่องที่วางแผนไว้** — ที่เหลือเลื่อนไป 1 ช่วง ไม่มีใครเสียหาย
>
> ⚠️ ไม่ต้องรอ 31 ส.ค. ถึงจะเริ่มเรื่องปาล์ม — **ปักหมุดคอมเมนต์ในคลิปเดิมได้วันนี้**
> คอมเมนต์ผูกกับคลิป ไม่ใช่ไบโอ จึงไม่กระทบแคมเปญ SMS ที่ยังเดินอยู่

### ข้อความไบโอต้องเปลี่ยนพร้อมลิงก์ทุกครั้ง

ถ้าเปลี่ยนแต่ลิงก์ ข้อความจะบอกเรื่องหนึ่งแต่ลิงก์พาไปอีกเรื่อง — คนอ่านแล้วสับสน ไม่กด

```
บรรทัด 1 (คงที่)  สร้างธุรกิจและวางระบบด้วยตัวคนเดียว ด้วยทีม AI
บรรทัด 2 (เปลี่ยน) ← ตามช่วง ดูด้านล่าง
```

| ช่วง | บรรทัดที่ 2 |
|---|---|
| SMS ปลอม | `เช็ก SMS ปลอม อ่านฟรี ไม่ต้องสมัคร 👇` |
| ราคาปาล์ม | `ราคาตก ต้นทุนเท่าไรถึงไม่ขาดทุน อ่านฟรี 👇` |
| ต้นทุน/ราคา | `ตั้งราคายังไงไม่ขาดทุน อ่านฟรี 👇` |
| หาลูกค้า | `หาลูกค้า 10 คนแรกโดยไม่ยิงแอด 👇` |
| ไม่มีทุน | `เริ่มธุรกิจไม่มีทุน 7 ก้าว อ่านฟรี 👇` |
| แผนธุรกิจ | `ทำแผนธุรกิจเสร็จใน 1 ชม. อ่านฟรี 👇` |
| ไม่ต้องเก่ง AI | `ลองใช้ทีม AI ฟรี ไม่ต้องสมัคร 👇` |

### ✅ Checklist วันสลับช่วง (~5 นาที)

- [ ] TikTok — ✏️ → **ลิงก์** → เปลี่ยน URL (`?s=tt`)
- [ ] TikTok — ✏️ → **ประวัติ** → เปลี่ยนบรรทัดที่ 2
- [ ] Instagram — แก้ไขโปรไฟล์ → **เว็บไซต์** (`?s=ig`)
- [ ] Instagram — แก้ข้อความไบโอบรรทัดที่ 2
- [ ] เปิดจากมือถือจริง กดลิงก์ 1 ครั้ง → เข้าถูกหน้า
- [ ] **คลิปเด่นของช่วงที่ผ่านมา** — ปักหมุดคอมเมนต์ที่มี URL เดิม
      (คอมเมนต์ผูกกับคลิป ไม่ถูกสลับตามไบโอ = ยังกู้คนจากคลิปเก่าได้)

> **Facebook / YouTube / LINE ไม่ต้องแตะเลย** — ลิงก์ผูกกับโพสต์แต่ละอันอยู่แล้ว
> โพสต์เรื่องไหนใส่ลิงก์เรื่องนั้นตอนโพสต์ จบในตัว

**ช่องชื่อ = ใส่ hook ไม่ใช่ลิงก์** · ลิงก์ในช่องชื่อกดไม่ได้และกินที่ hook ทิ้ง

| ไม่ต้องเก่ง AI | `https://ceoaithailand.org/ai?s=yt&c=4a` |
| ลูกค้า 10 คนแรก | `https://ceoaithailand.org/customer?s=yt&c=5a` |
| SMS ปลอม | `https://ceoaithailand.org/sms?s=yt&c=6a` |
| ราคาคอมขึ้นยุค AI | `https://ceoaithailand.org/pc?s=yt&c=7a` |

## 🎵 TikTok / Reels — ⚠️ ต้องตั้งไบโอก่อน

**แคปชัน TikTok กดลิงก์ไม่ได้** — ทางเดียวคือลิงก์ในไบโอ

**ก่อนโพสต์:**
1. โปรไฟล์ → **✏️ มุมซ้ายบน** (แก้ไขโปรไฟล์) → **ลิงก์** → ช่อง **URL**
2. ใส่ `https://ceoaithailand.org/sms?s=tt` (ตามช่วงในปฏิทินด้านบน)
3. ครบช่วงแล้วสลับตามตาราง — **ไม่ใช่สลับตามคลิป**

**ข้อควรรู้ TikTok (จากหน้างานจริง):**
- ต้องเป็น **บัญชีธุรกิจ** ช่อง "ลิงก์" ถึงจะโผล่ (เปลี่ยนฟรี · ☰ → การตั้งค่า → บัญชี)
- URL ที่**พิมพ์ในข้อความไบโอกดไม่ได้** — ที่กดได้คือบรรทัดตัวหนาที่ TikTok สร้างให้เท่านั้น
  (อย่าพิมพ์ URL ซ้ำในไบโอ จะขึ้น 2 บรรทัดเหมือนกันจนคนกดผิด)
- เมนู **"ปุ่มดำเนินการ"** ใส่ลิงก์เว็บ**ไม่ได้** — มีแค่ อีเมล/โทร/ที่อยู่/แอป
  (ช่อง "แอป" ไว้ใส่ลิงก์ App Store เท่านั้น อย่าเอา URL เว็บไปใส่)
  → ใส่ **อีเมล** แทน จะได้ปุ่มติดต่อจริงบนโปรไฟล์ สำหรับคนที่อยากคุยงาน
- **ปุ่มลิงก์บนตัวคลิป** ได้จาก **โปรโมท (เสียเงิน)** เท่านั้น และต้องเลือกเป้าหมาย
  **"การเข้าชมเว็บไซต์เพิ่มขึ้น"** — ถ้าเลือก "เพิ่มผู้ติดตาม" จะไม่มีปุ่มลิงก์เลย
- แก้แคปชันย้อนหลังอาจทำไม่ได้ → **ปักหมุดคอมเมนต์**แทน · **ห้ามลบคลิปแล้วโพสต์ใหม่**
  (วิว/คอมเมนต์/งบโฆษณาหายหมด)

**ในแคปชันเขียนชี้ทางเสมอ:**
```
วิธีเช็ก 5 ข้อ อยู่ในลิงก์ใต้โปรไฟล์ 👆 อ่านฟรี ไม่ต้องสมัคร
```

> 🔴 **ถ้าไม่ตั้งไบโอ = วิวเท่าไรก็เข้าเว็บ 0 คน** — เคยเกิดแล้วครั้งหนึ่งกับคลิปที่ได้วิวเกือบสองหมื่น
