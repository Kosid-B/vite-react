# สคริปต์คลิปสั้น 12 ตัว + หัวข้อข่าว — แผน 4 สัปดาห์

> ทุกสคริปต์ 10–15 วินาที · hook ใน 3 วินาทีแรก · อ้างเฉพาะสิ่งที่ระบบทำได้จริง
> A = เน้นประโยชน์ตรง · B = เน้นเรื่องราว/ความรู้สึก

---

## ⚠️ 3 จุดที่ต้องปรับในแผน ก่อนเริ่ม

**1. "โพสต์รีวิว/ผลลัพธ์ผู้ใช้งานจริง (ถ้ามี)" — ตอนนี้ยังไม่มี ห้ามแต่ง**
ผู้ใช้จริง = 1 (บัญชีคุณเอง) การสร้างรีวิวปลอมกับแบรนด์ที่ขายความน่าเชื่อถือด้าน ISO
คือความเสี่ยงที่ไม่คุ้มเลย — ถ้าถูกจับได้ครั้งเดียว จบ
**ใช้แทน:** "ผมทำงานวางระบบให้โรงงานและบริษัทมา 25 ปี" — จริง ตรวจสอบได้ และแรงกว่ารีวิวปลอม

**2. "ข้อเสนอพิเศษ 1 เดือนนี้เท่านั้น" — ใช้ได้ ถ้าทำจริง**
ถ้าตั้งเส้นตายแล้วพอถึงวันจริงไม่ปิด หรือเปิดใหม่เดือนหน้า = คนจำได้ และจะไม่เชื่ออีกเลย
**ทางที่ปลอดภัยกว่า:** ใช้เส้นตายที่มีอยู่จริง เช่น 30 ส.ค. (ปรับปรุงข้อมูลซิม) หรือผูกกับจำนวนที่คุณรับไหวจริง
เช่น "รับตรวจสุขภาพธุรกิจฟรี 10 รายแรก" — จำกัดเพราะเวลาคุณมีจำกัดจริง ไม่ใช่แกล้งจำกัด

**3. คลิป 8–10 ตัวใน 1 สัปดาห์ ด้วยผู้ติดตาม 46 คน**
อัลกอริทึมจะยังไม่ดันมากในช่วงแรก อย่าตกใจถ้า 3–4 คลิปแรกวิวน้อย
**ตัวชี้วัดที่ควรดูสัปดาห์แรกไม่ใช่วิว แต่คือ "อัตราดูจบ" (watch-through)** — คลิปไหนคนดูจบเยอะ นั่นคือตัวที่ควรทำต่อ

# 📰 หัวข้อข่าว — หาเองอย่างไรให้ปลอดภัย

**อย่าให้ผมแต่งข่าวหรือสถิติให้** — ถ้าอ้างผิดแล้วมีคนทัก แบรนด์ที่ปรึกษาเสียหายหนักกว่าที่ได้

## แหล่งที่อ้างได้อย่างมั่นใจ

| แหล่ง | ใช้กับเรื่อง |
|---|---|
| สสว. (OSMEP) | สถิติ SME ไทย · จำนวนผู้ประกอบการ · ปัญหาที่พบ |
| ธปท. (แบงก์ชาติ) | ภาวะเศรษฐกิจ · สินเชื่อ SME · หนี้ครัวเรือน |
| กรมพัฒนาธุรกิจการค้า | ยอดจดทะเบียนธุรกิจใหม่รายเดือน |
| สภาอุตสาหกรรม / หอการค้า | ดัชนีความเชื่อมั่น · ต้นทุนผู้ประกอบการ |
| กสทช. · ตำรวจไซเบอร์ | ภัยมิจฉาชีพ · SMS ปลอม |

## สูตรทำคลิปข่าว 3 ขั้น

```
1. ข่าวจริง 1 ประโยค + บอกแหล่ง
   "กรมพัฒนาธุรกิจฯ รายงานว่าเดือนที่แล้วมีธุรกิจจดทะเบียนใหม่ X ราย"

2. แปลว่าอะไรกับคนดู
   "แปลว่าคู่แข่งคุณเพิ่มขึ้นทุกเดือน"

3. สิ่งที่ทำได้วันนี้ + ลิงก์
   "สิ่งที่ทำให้อยู่รอดไม่ใช่เปิดเร็วกว่า แต่คือรู้ต้นทุนตัวเอง"
```

**กฎเหล็ก:** ถ้าหาตัวเลขจริงไม่ได้ **ตัดตัวเลขทิ้ง** แล้วพูดเชิงคุณภาพแทน
ห้ามใส่ตัวเลขที่ยังไม่ได้ตรวจเด็ดขาด

# 📊 ตัวชี้วัดที่ควรดูจริง (แก้จากแผนเดิม)

| สัปดาห์ | ดูตัวนี้เป็นหลัก | ทำไม |
|---|---|---|
| 1 | **อัตราดูจบ (watch-through)** | ยังไม่มีคนตาม วิวจะน้อยเป็นปกติ — ดูว่าคอนเทนต์ดีไหมจากคนที่ได้ดู |
| 2 | อัตราเข้าโปรไฟล์ | เกณฑ์ปกติ 3–5% · ถ้าต่ำกว่า 1% แปลว่า hook ยังไม่ดึง |
| 3 | คลิกจากไบโอ | เกณฑ์ปกติ 10–20% ของคนเข้าโปรไฟล์ |
| 4 | **จำนวนคนสมัคร** | ตัวเลขเดียวที่สำคัญจริง |
