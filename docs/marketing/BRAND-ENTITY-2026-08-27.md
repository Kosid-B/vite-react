### สิ่งที่ตรวจแล้วพบว่าขาด

| สิ่งที่ AI ต้องใช้ | สถานะก่อนหน้า |
|---|---|
| ประโยคนิยามตรง ๆ ("X คือ …") ที่หยิบไปอ้างได้ | 🔴 ไม่มีหน้าไหนมี |
| รายการ "ไม่ใช่อะไร" ที่ระบุชื่อจริง | 🔴 `disambiguatingDescription` แยกเราออกจาก **Siam AI** ซึ่งไม่ใช่ชุดที่สับสนจริง |
| หน้า `/about` | 🔴 ไม่มีเลย |

### ทำแล้ว (รอบสอง)

- **หน้า `/about`** server-rendered + `AboutPage` schema + อยู่ใน sitemap (priority 0.9)
  ขึ้นต้นด้วย *"CEO AI Thailand คือ **ซอฟต์แวร์ (SaaS)** สำหรับผู้ประกอบการ SME ไทย…"*
- **รายการ "ไม่ใช่อะไร"** ระบุครบทั้ง 4 ชื่อที่ AI หยิบมาปน + Siam AI
  ⚠️ ระบุเพียงว่า **เป็นคนละองค์กร** — เทสต์ห้ามมีถ้อยคำเปรียบเทียบว่าใครดีกว่าใคร (เขาเป็นบุคคลที่สาม)
- **`disambiguatingDescription`** เปลี่ยนให้ตรงกับชุดที่สับสนจริง
- **`llms.txt`** เพิ่มบล็อก "CEO AI Thailand คืออะไร" + รายการ "ไม่ใช่" ชุดเดียวกัน
- ลิงก์ `rel="me"` ออกไปทุกโปรไฟล์ที่มี URL จริง

🔴 **ผมยืนยันผลไม่ได้** — เข้า SERP/AI Overview ไม่ได้ (proxy 403) และไม่มีสิทธิ์ GSC
สิ่งที่ยืนยันได้คือ **หน้าถูกสร้างจริง เสิร์ฟจริง อยู่ใน sitemap จริง และข้อความที่เครื่องอ่านได้ถูกต้อง**
⇒ **เจ้าของต้องเป็นคนตรวจผล**: ส่ง `ceoaithailand.org/about` เข้า URL Inspection ใน Search Console แล้วกด "Request Indexing"

## ระบบตรวจ: "ตลาดและ Search Engine เริ่มจำแบรนด์ถูกหรือยัง"

> เจ้าของสั่ง 27 ส.ค. 2569: *"ไม่ได้แค่ 'มี Dashboard' แต่มีระบบตรวจว่าตลาดและ Search Engine
> เริ่มจำแบรนด์ถูกต้องหรือยัง และเชื่อม Website + Google + Facebook + YouTube
> กลับเข้าสู่ Growth Loop เดียวกันได้"*

**ที่อยู่**: `src/lib/brandVisibility.ts` (ตรรกะ · pure) + `src/components/BrandVisibilityPanel.tsx`
(แผงในแท็บเวิร์กสเปซ วางต่อจาก `ReachFunnelPanel`)

### ลำดับคอขวด — ห้ามข้ามขั้น

```
① entityConsistency  เราพูดชื่อตัวเองตรงกันเองหรือยัง   (รีโปอ่านได้เอง)
② indexedPages       Google เห็นหน้าเราหรือยัง            (เจ้าของอ่านจาก GSC)
③ brandedRank        ค้นชื่อเราแล้วเจอเราไหม               (เจ้าของอ่านจาก GSC)
④ externalMentions   มีคนอื่นยืนยันไหม                    (ค้นด้วยมือ)
⑤ shareOfSearch      คนเริ่มค้นชื่อเรามากขึ้นไหม            (Google Trends)
```

แผงคืน **คอขวดข้อเดียว** ตามลำดับนี้ ไม่ใช่รายการงานยาว ๆ — ขั้นก่อนหน้าไม่เต็ม
ห้ามรายงานว่าคอขวดอยู่ขั้นถัดไป (เทสต์บังคับ)

### กฎ 3 ข้อที่โมดูลนี้ยืนอยู่บน

| กฎ | ทำไม |
|---|---|
| **`null` = ตรวจไม่ได้ ≠ 0** | ช่องว่างในแผงคือ "ยังไม่ได้ตรวจ" — เว้นว่างแล้วต้องกลับเป็น `undefined` ไม่ใช่ `0` (เทสต์ล็อกทั้งฝั่ง lib และฝั่ง UI) |
| **ตาบอดเกินครึ่ง = ไม่ให้คะแนนรวม** | `Brand Entity Health: 41/100` ที่ดูน่าเชื่อแต่คำนวณจากช่องว่าง = ตัวเลขที่อันตรายที่สุด · `MAX_BLIND_RATIO = 0.5` |
| **ไม่มีเป้า = ไม่เข้าคะแนน** | ผู้ติดตาม Facebook 99,999 คน ไม่ได้แปลว่าเครื่องจำแบรนด์เราถูก — เป็นบริบท ไม่ใช่ตัววัด (ledger #61) |

**เกณฑ์ทุกตัวติดป้าย `ThresholdStatus`** จาก `decisionRules` — วันนี้เป็น `policy`/`hypothesis` ทั้งหมด
🔴 ห้ามมีตัวไหนเป็น `validated` จนกว่าจะมีผลจริงของเราเอง (เทสต์บังคับ)

### สถานะจริงวันนี้ (27 ส.ค. 2569)

- **คะแนนรวม = `null`** (ตรวจไม่ได้ 4 จาก 5 ตัวที่เข้าคะแนน) — ตรงตามกฎ ไม่ใช่บั๊ก
- **คอขวด = `entityConsistency`** — โปรไฟล์ที่ต้องมี URL ครบ 4 ช่องทาง มีจริง 2 (เว็บ + YouTube)
- ⇒ งานถัดไปที่ระบบคืนออกมาเอง: **ให้เจ้าของส่ง URL ของ Facebook Page และ LinkedIn มาใส่ `config.SOCIAL`**
  (ห้ามเดา URL เอง — เทสต์ใน `brandEntity.test.ts` กันไว้)
