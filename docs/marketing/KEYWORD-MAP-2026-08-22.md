## 🔴 กฎแม่ของ skill นี้ — และมันแก้ความเข้าใจเรื่อง #ธุรกิจ #ต้นทุน #กำไร

> **"คำค้นที่ดีที่สุด ไม่ใช่คำที่คนค้นเยอะที่สุด —
> แต่คือคำที่ *เนื้อหาเราติดอันดับได้จริง* และ *คนค้นมีโอกาสเป็นลูกค้ามากที่สุด*"**

**คุณถูกที่ว่าต้องใช้คำที่คนค้นจริง ไม่ใช่ชื่อหมวดหมู่สินค้า** — แต่มีชั้นที่ต้องระวัง:

| ประเภทคำ | ตัวอย่าง | เว็บเราติดอันดับได้ไหมตอนนี้ |
|---|---|---|
| **Head term** (1–2 คำ) | `ธุรกิจ` · `ต้นทุน` · `กำไร` | ❌ **ไม่ได้** — แข่งกับเว็บที่อยู่มาหลายปี · เว็บเราเพิ่ง index เมื่อ ~16 ส.ค. |
| **Body** (2–3 คำ) | `คิดต้นทุนสินค้า` · `จุดคุ้มทุน` | 🟡 ยาก แต่พอมีทาง |
| **Long-tail** (4+ คำ) | `ตั้งราคาขายยังไงไม่ให้ขาดทุน` | ✅ **นี่คือที่ที่เราชนะได้** |

⇒ ใช้คำ **ธุรกิจ/ต้นทุน/กำไร** ต่อไป — แต่ใช้เป็น **ส่วนหนึ่งของประโยคยาว** ไม่ใช่คำเดี่ยว
(anti-pattern ที่ skill เตือนตรง ๆ: *"เว็บใหม่ยิงคำ volume สูงอย่างเดียว = ไม่มีวันติด"*)

🟢 **ข่าวดี: บทความที่เรามีอยู่ทำถูกหลักนี้แล้ว** — ดูตารางถัดไป

## 2. 🔴 ลำดับที่แก้แล้ว — "ธุรกิจ" นำ · "ISO" ตาม (เจ้าของยืนยัน 22 ส.ค. 2569)

**ฉบับแรกผมจัดให้คำ ISO/PDPA ขึ้นก่อน** เพราะเห็นว่ากลุ่มนั้นมีเงินและค้นหาอยู่แล้ว — **ผิดลำดับ**

| # | เหตุผลที่ธุรกิจต้องนำ |
|---|---|
| ① | CEO AI **สร้างมาสำหรับคนทำธุรกิจ** · compliance เป็นฟีเจอร์เสริม ไม่ใช่ตัวสินค้า |
| ② | 🔴 **นำด้วย ISO = แข่งกับบริษัทแม่ตัวเอง** — B.Training ขายที่ปรึกษา ISO **฿50,000–85,000/โปรเจกต์** ⇒ เสียรายได้หลักหมื่นเพื่อได้ค่าสมาชิกหลักพัน |
| ③ | **ตลาดต่างกัน ~30 เท่า** — ISO 50,000–100,000 ราย vs เจ้าของธุรกิจ ~3.2 ล้านราย |

### ⏳ คำกลุ่ม ISO/audit — ยังทำ แต่เป็นชั้นที่ 2

ประตู `seg=audit` เปิดแล้ว (รับคนที่ค้นหาเอง) — **แต่ยังไม่ต้องรีบเขียนบทความ ISO**
เพราะทุกชิ้นที่เขียนด้วยคำ ISO จะไปแข่งกับงานที่ปรึกษาของ B.Training เอง

🔓 **เขียนเมื่อไร**: เมื่อมีบทความสาย "ธุรกิจ" ครบและติดอันดับแล้ว
แล้วค่อยเขียนแบบ **"ระบบธุรกิจนำ · ผ่าน audit เป็นผลพลอยได้"** ไม่ใช่ "สอนทำ ISO"

> 🧠 กฎที่ต้องจำ: **เรื่อง "ระบบ" ขายได้โดยไม่ต้องพูดคำว่า ISO เลยสักครั้ง**
> *"ป่วยวันเดียวร้านหยุด"* คือปัญหาเดียวกันกับที่ ISO แก้ — แต่พูดด้วยภาษาที่เจ้าของธุรกิจใช้จริง

## 3. ทำไมต้องเปิด Search Console → ประสิทธิภาพ ก่อนเขียนชิ้นแรก

ตารางข้างบนคือ **การคาดเดาที่มีเหตุผล** ไม่ใช่ข้อมูล
เรามี GSC ที่เก็บข้อมูลมาตั้งแต่ ~20 ก.ค. แล้ว ⇒ **มีคำตอบจริงรออยู่**

สิ่งที่ต้องดึงมา (3 อย่าง):

| ดูอะไร | ใช้ตัดสินใจอะไร |
|---|---|
| **คำค้น (Queries)** เรียงตาม **การแสดงผล (Impressions)** | คำที่ Google เอาเราไปโชว์แล้ว — **ของจริง ไม่ต้องเดา** |
| คำที่ **impressions สูง แต่คลิกต่ำ** | เราโผล่แล้วแต่พาดหัวไม่ชวนกด ⇒ **แก้ title ได้ทันที ไม่ต้องเขียนใหม่** |
| คำที่ **อันดับ 8–20** | ใกล้ติดหน้าแรก ⇒ **เติมเนื้อหาชิ้นเดิม คุ้มกว่าเขียนชิ้นใหม่** |

> 🧠 ข้อ 2 กับ 3 คือ **งานที่ให้ผลเร็วที่สุดในเอกสารนี้** — ไม่ต้องผลิตอะไรใหม่เลย

## 4. หา "ประสิทธิภาพ" ตรงไหน

🟡 **ผมเปิด Search Console เองไม่ได้ (ต้องล็อกอินบัญชีคุณ) และเปิด support.google.com ก็ไม่ได้**
⇒ ทางที่แน่นอนที่สุดคือ **เปิดด้วยลิงก์ตรง** ไม่ต้องหาในเมนู:

**ถ้าเป็น Domain property:**
```
https://search.google.com/search-console/performance/search-analytics?resource_id=sc-domain%3Aceoaithailand.org
```

**ถ้าเป็น URL-prefix property:**
```
https://search.google.com/search-console/performance/search-analytics?resource_id=https%3A%2F%2Fceoaithailand.org%2F
```

ลองอันแรกก่อน · ถ้าขึ้นว่าไม่มีสิทธิ์/ไม่พบ ให้ลองอันที่สอง

**หรือหาจากเมนู** (🟡 ผมยืนยัน UI ปัจจุบันไม่ได้): กดปุ่ม **☰** มุมซ้ายบน (ปุ่มเดียวกับที่พาไป "การจัดทำดัชนีหน้า")
แล้วมองหา **"ประสิทธิภาพ"** — ปกติอยู่ใกล้บนสุด ใต้ "ภาพรวม"

**ในหน้านั้นให้กดแท็บ "คำค้นหา"** แล้วเปิดช่อง **"การแสดงผล"** (Impressions) กับ **"ตำแหน่งเฉลี่ย"** ด้วย
(ค่าเริ่มต้นมักติ๊กแค่ "จำนวนคลิก" ซึ่งของเราอาจเป็น 0 — **แต่ impressions ไม่ใช่ 0 แน่ ๆ ถ้า index แล้ว 12 หน้า**)

📎 **ถ้าส่งภาพหน้าจอตารางคำค้นมา ผมจะแปลงเป็นแผนคอนเทนต์ให้ทันที** — และตารางในข้อ 2
จะถูกแทนที่ด้วยคำที่คนค้นจริง แทนที่จะเป็นคำที่ผมเดา

| ทำอะไร | เหตุผล |
|---|---|
| แก้ title `/calc` เป็น **"คำนวณต้นทุนและกำไรต่อชิ้น — ..."** | คำที่คนพิมพ์ต้องอยู่ต้นประโยค · เดิมขึ้นต้นด้วย "คิดให้ดูเลย" ที่ไม่มีใครค้น |
| เปิด `seg=audit` + ขยายคำทริกเกอร์ (audit · มอก · pdpa · ตรวจประเมิน · ต่ออายุ) | ประตูรับกลุ่มที่ค้นหาอยู่แล้ว |

🔴 **ที่ยังไม่ได้ทำ**: บทความสำหรับกลุ่ม audit — **ประตูเปิดแล้วแต่ยังไม่มีถนน**
