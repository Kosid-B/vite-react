# แหล่งข้อมูลตลาดไทย & การอ้างอิงอย่างโปร่งใส (Thai Market Data & Citation)

> ใช้ทุกครั้งก่อนใส่ตัวเลขลงในคอนเทนต์ ข้อเสนอ หรือรายงานให้ลูกค้า
> **ตัวเลขที่อ้างไม่ได้ = อย่าใส่** ไม่ว่าจะดูดีแค่ไหน

---

## A. หลักการหลัก (Core Principles)

1. **ตัวเลขไม่ได้ทำให้น่าเชื่อถือ — ตัวเลขที่ตรวจสอบได้ต่างหากที่ทำ**
   คนอ่านสมัยนี้เห็นตัวเลขลอย ๆ ทุกวันจนชิน สิ่งที่สะดุดตาคือ "จากสำนักงานสถิติแห่งชาติ ปี 2568"
   เพราะมันบอกว่าเราตรวจมาแล้ว และเขาตรวจซ้ำได้

2. **สำหรับแบรนด์ที่ปรึกษา การอ้างผิดครั้งเดียวแพงกว่าที่ได้จากคอนเทนต์นั้นทั้งปี**
   เราขายความน่าเชื่อถือ ไม่ใช่ขายคอนเทนต์ — ตัวเลขผิดหนึ่งตัวทำลายสิ่งที่สร้างมา 25 ปีได้

3. **หาไม่เจอ ให้ตัดทิ้ง อย่าประมาณ**
   "ประมาณ 70%" ที่ไม่มีที่มา อันตรายกว่าการไม่ใส่ตัวเลขเลย
   พูดเชิงคุณภาพได้ ("SME ส่วนใหญ่เจอปัญหานี้") ถ้าเป็นสิ่งที่เรารู้จากประสบการณ์จริง — แต่ต้องบอกว่ามาจากประสบการณ์

4. **ข้อมูลรัฐ > รายงานเอกชน > สื่อ**
   สื่อมักสรุปต่อจากรายงานอีกที ให้ตามกลับไปหาต้นทางเสมอ ถ้าตามไม่ถึงต้นทาง = ยังใช้ไม่ได้

### B2. รายงานเชิงลึกพฤติกรรมคน (Gen X / Y / Z)

| รายงาน | ใช้กับเรื่อง |
|---|---|
| **Deloitte Global Gen Z & Millennial Survey** | ทัศนคติ · ความกังวลเรื่องการเงิน · แรงจูงใจในการเริ่มธุรกิจของ Gen Y/Z |
| **Digital Insights Thailand** (Content Shifu + YouGov) | พฤติกรรมใช้สื่อดิจิทัลแยกตามเจน · ช่องทางที่เข้าถึงง่ายที่สุด |
| **WPP Thailand Digital Playbook** | พฤติกรรมผู้บริโภคไทย · ความไว้วางใจ · แนวโน้มการตลาดดิจิทัล |
| **Kantar / Nielsen Thailand** | ความเชื่อถือแบรนด์ · ประสิทธิภาพสื่อโฆษณา |
| **Statista** | สถิติโลก+ไทยครอบคลุมทุกอุตสาหกรรม (ตามต้นทางที่เขาอ้างต่อได้) |

### B3. รูปแบบการอ้างอิงที่ถูกต้อง

**ต้องมีครบ 2 อย่างเสมอ: แหล่ง + ปี**

✅ ใช้ได้
```
"จากข้อมูลสำนักงานสถิติแห่งชาติ ปี 2568 พบว่า…"
"รายงาน Deloitte Global 2026 ชี้ว่า…"
"กรมพัฒนาธุรกิจการค้า รายงานว่า ณ เดือนกรกฎาคม 2568…"
```

❌ ใช้ไม่ได้
```
"จากการวิจัยพบว่า…"           ← วิจัยของใคร ปีไหน
"มีการศึกษาระบุว่า…"           ← เหมือนกัน
"ผู้เชี่ยวชาญบอกว่า…"          ← ผู้เชี่ยวชาญคนไหน
"ประมาณ 70% ของ SME…"        ← ประมาณจากอะไร
```

### B4. ระดับความมั่นใจ — บอกให้ชัดว่าอันไหนคือข้อมูล อันไหนคือความเห็น

| ระดับ | เขียนยังไง |
|---|---|
| ข้อมูลที่ตรวจแล้ว | "จาก [แหล่ง] ปี [ปี] พบว่า…" |
| ประสบการณ์ตรงของเรา | "จากที่ผมวางระบบให้โรงงานมา 25 ปี ผมเห็นว่า…" |
| ความเห็น/การตีความ | "ผมคิดว่าแปลว่า…" / "ในมุมมองผม…" |

**อย่าให้ 3 อย่างนี้ปนกันจนคนอ่านแยกไม่ออก** — นี่คือเส้นแบ่งระหว่างที่ปรึกษากับคนขายของ

## C. Playbook 5 ขั้น

| ขั้น | ทำอะไร | รู้ได้ยังไงว่าผ่าน |
|---|---|---|
| 1 | เขียนสิ่งที่อยากพูดก่อน โดยยัง**ไม่ใส่ตัวเลข** | ประโยคยังสื่อสารได้แม้ไม่มีตัวเลข |
| 2 | ถามว่า "ตัวเลขนี้จะทำให้คนเชื่อมากขึ้นจริงไหม" | ถ้าไม่ → ไม่ต้องหา ประหยัดเวลา |
| 3 | เปิดตาราง B1 เลือกแหล่งที่ตรงกับคำถาม แล้วหาตัวเลขจริง | เห็นตัวเลขในหน้าเว็บของหน่วยงานเอง ไม่ใช่ในข่าวที่อ้างต่อ |
| 4 | จดไว้ 3 อย่าง: **ตัวเลข · แหล่ง · ปี** (+ ลิงก์) | เอากลับมาตรวจซ้ำได้ในอีก 6 เดือน |
| 5 | เขียนอ้างอิงตามรูปแบบ B3 | คนอ่านตามไปตรวจเองได้ |

**ถ้าตกที่ขั้น 3 (หาไม่เจอ) → กลับไปขั้น 1 แล้วเขียนใหม่โดยไม่ใช้ตัวเลข**

## D. กับดักที่คนพลาดบ่อย

- **อ้างข่าวที่อ้างรายงานอีกที** — สื่อสรุปผิดบ่อยมาก ตามกลับไปต้นทางเสมอ
- **ใช้ข้อมูลเก่าโดยไม่บอกปี** — ตัวเลข SME ปี 2562 กับ 2568 คนละเรื่องกัน ถ้าไม่บอกปีถือว่าทำให้เข้าใจผิด
- **ตัดทอนข้อความให้เข้าทางเรา** — รายงานบอกว่า "70% สนใจแต่ 20% พร้อมจ่าย" แล้วเราหยิบมาแค่ 70% = บิดเบือน
- **แปลง % เป็นจำนวนคนเอง** โดยไม่รู้ฐานที่เขาใช้ — ผิดง่ายมากและตรวจได้
- **เอาข้อมูลต่างประเทศมาพูดเหมือนเป็นของไทย** — พฤติกรรม Gen Z อเมริกา ≠ Gen Z ไทย
- **ปนความเห็นกับข้อมูลจนแยกไม่ออก** — คนอ่านที่ระวังจะจับได้ และจะไม่เชื่อทั้งย่อหน้า

**เส้นแบ่งจริยธรรม**
- ทำได้: เลือกตัวเลขที่เกี่ยวข้องกับเรื่องที่พูด · ตีความและบอกว่าเป็นการตีความ
- ห้ามทำ: ดัดแปลงตัวเลข · ตัดบริบทที่เปลี่ยนความหมาย · อ้างแหล่งที่ไม่ได้อ่านจริง

## E. Checklist ก่อนกดโพสต์/ส่งงาน

- [ ] ทุกตัวเลขมี **แหล่ง + ปี** กำกับ
- [ ] ตามลิงก์กลับไปถึง**ต้นทาง**แล้ว ไม่ใช่หยุดที่ข่าว
- [ ] ตัวเลขยัง**ไม่เก่าเกินไป**สำหรับเรื่องที่พูด (เศรษฐกิจ/ราคา = ควรไม่เกิน 1 ปี)
- [ ] ไม่ได้ตัดบริบทที่เปลี่ยนความหมาย
- [ ] แยกชัดว่าอันไหน**ข้อมูล** อันไหน**ประสบการณ์เรา** อันไหน**ความเห็นเรา**
- [ ] ถ้ามีคนถามว่า "เอามาจากไหน" ตอบได้ทันทีภายใน 10 วินาที

## F. บทเรียนจากหน้างานจริง

**เคส: ตัวเลขที่ไม่ได้ใส่ กลับทำให้น่าเชื่อถือกว่า**

- **สถานการณ์:** ทำคอนเทนต์เรื่องต้นทุนร้านอาหาร อยากใส่สถิติ "ร้านอาหารไทย X% เจ๊งใน 3 ปีแรก"
  ซึ่งเป็นตัวเลขที่เห็นคนแชร์กันเยอะมาก
- **สิ่งที่คนทั่วไปจะทำ:** ใส่ไปเลย เพราะเห็นคนอื่นใช้กันทั้งนั้น
- **สิ่งที่ทำแทน:** ตามหาต้นทาง — ปรากฏว่าตามไม่ถึงหน่วยงานไหนเลย
  เป็นตัวเลขที่ถูกอ้างต่อ ๆ กันมาจนไม่มีใครรู้ว่ามาจากไหน จึง**ตัดทิ้ง**
  แล้วเปลี่ยนไปพูดจากสิ่งที่ตรวจสอบได้แทน: "ต้นทุนต่อจานที่คุณคิดอยู่ ยังไม่ได้หักอะไรบ้าง"
- **ผลลัพธ์:** คอนเทนต์ที่ไม่มีสถิติเลย แต่ให้คนคำนวณของตัวเอง — คนมีส่วนร่วมมากกว่า
  เพราะตัวเลขของเขาเองน่าเชื่อถือกว่าสถิติของคนอื่นเสมอ
- **บทเรียนที่ทำซ้ำได้:**
  **ตัวเลขที่ดีที่สุดในคอนเทนต์ ไม่ใช่สถิติระดับประเทศ แต่คือตัวเลขของคนอ่านเอง**
  ถ้าทำให้เขาคำนวณของตัวเองได้ เราไม่ต้องพึ่งสถิติของใครเลย และไม่มีทางอ้างผิดด้วย
