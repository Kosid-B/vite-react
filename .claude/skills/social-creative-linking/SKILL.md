# ทำครีเอทีฟให้คนกดเข้าเว็บได้จริง (Social Creative Linking)

> ใช้ทุกครั้งก่อนโพสต์ภาพที่มีปุ่ม/CTA — โดยเฉพาะ Story, Reels, TikTok
> เพราะครีเอทีฟที่สวยแต่คนเข้าเว็บไม่ได้ = เสียทั้งงานออกแบบและจังหวะคอนเทนต์

---

## A. หลักการหลัก (Core Principles)

1. **ปุ่มในภาพไม่ใช่ปุ่ม — มันคือภาพของปุ่ม**
   ทุกแพลตฟอร์มเรนเดอร์ครีเอทีฟเป็นพิกเซล ไม่มีพื้นที่ไหนกดได้
   ปุ่มในภาพมีหน้าที่เดียวคือ **บอกว่าให้ทำอะไรต่อ** ส่วนลิงก์จริงต้องมาจากที่อื่นเสมอ

2. **คนที่สนใจจะ "พิมพ์ตาม" ไม่ใช่ "กด"**
   โดยเฉพาะคนดู Story/TikTok ที่มือถืออยู่ในมือ เห็นแล้วสนใจ ก็พิมพ์ตามที่จำได้
   ดังนั้น URL ที่โชว์ในภาพต้อง **จำได้จากการเห็นครั้งเดียว** ไม่ใช่ URL จริงที่ยาว

3. **แต่ละแพลตฟอร์มมีกลไกลิงก์ไม่เหมือนกัน — วางผิดที่ = ลิงก์ตาย**
   สิ่งที่ทำงานบน Facebook feed ใช้ไม่ได้บน TikTok
   ต้องรู้ว่าแพลตฟอร์มนั้น "อนุญาตให้ลิงก์อยู่ตรงไหน" ก่อนออกแบบ CTA

4. **ถ้าวัดไม่ได้ว่าคอนเทนต์ชิ้นไหนพาคนมา = โพสต์ต่อไปก็ยังเดาอยู่ดี**
   UTM ต้องติดให้อัตโนมัติฝั่งเซิร์ฟเวอร์ ไม่ใช่ให้ผู้ใช้พิมพ์ query string เอง (ไม่มีใครพิมพ์)

---

## B. เครื่องมือ (Tools)

### B1. ตารางกลไกลิงก์ต่อแพลตฟอร์ม — ดูก่อนออกแบบทุกครั้ง

| แพลตฟอร์ม | ลิงก์วางตรงไหนถึงกดได้ | ข้อควรรู้ |
|---|---|---|
| Facebook feed | URL ในแคปชัน | กดได้อัตโนมัติ · เป็นช่องทางเดียวที่ **แชร์ต่อได้** |
| Facebook / IG Story | Link sticker ตอนโพสต์ | ต้องติดเอง ไม่เกี่ยวกับภาพ |
| LINE / กลุ่มไลน์ | วาง URL เป็นข้อความ | กดได้ · ส่งต่อง่ายที่สุดในไทย |
| TikTok / Reels | **ไบโอเท่านั้น** | แคปชันกดไม่ได้ → ถ้าไม่ตั้งไบโอ = traffic เป็นศูนย์ |
| YouTube | คำบรรยาย / ปักหมุดคอมเมนต์ | ลิงก์ในคลิปกดไม่ได้ |

### B2. กฎตั้งลิงก์สั้น — ต้องพิมพ์ถูกจากการเห็นครั้งเดียว

| กฎ | เหตุผล |
|---|---|
| ไม่เกิน 12 ตัวอักษรหลังโดเมน | ยาวกว่านี้คนจำไม่ทันตอน Story ผ่านไป |
| ทำทั้งไทยและอังกฤษของเรื่องเดียวกัน | คนพิมพ์ตามคีย์บอร์ดที่เปิดอยู่ตอนนั้น |
| เป็นคำที่ "เดาได้" จากเนื้อหา | `/ราคา` เดาถูก · `/p1` เดาไม่ถูก |
| หลีกเลี่ยงตัวที่สับสน | `l` กับ `1` · `0` กับ `O` |
| ปลายทางต้องเป็นพาธภายในเว็บเรา | กัน open redirect ที่ถูกเอาไปใช้หลอกคน |

### B3. UTM ที่ติดให้อัตโนมัติ

ให้เซิร์ฟเวอร์ redirect พร้อมแนบ UTM เอง ผู้ใช้พิมพ์แค่ `เว็บเรา/sms`

```
ผู้ใช้พิมพ์ : ceoaithailand.org/sms
เซิร์ฟเวอร์ : 302 → /blog/sim-update-scam-check
              ?utm_source=social&utm_medium=organic&utm_campaign=sim_scam
```

**campaign ต้องไม่ซ้ำกันต่อคอนเทนต์หนึ่งชิ้น** — ไม่งั้นแยกไม่ออกว่าชิ้นไหนได้ผล

### B4. โครง CTA ในภาพ (3 ชั้น อย่าขาดชั้นไหน)

```
[ปุ่ม]        ← บอกว่าให้ทำอะไร      เช่น "อ่านวิธีเช็ก →"
[URL สั้น]    ← บอกว่าไปที่ไหน       เช่น ceoaithailand.org/sms
[เหตุผล]      ← บอกว่าทำไมต้องรีบ    เช่น "อ่านฟรี ไม่ต้องสมัคร"
```

ขาดชั้น URL = คนสนใจแต่ไปต่อไม่ได้ · ขาดชั้นเหตุผล = คนเห็นแต่ไม่กด

## C. Playbook 5 ขั้น

| ขั้น | ทำอะไร | รู้ได้ยังไงว่าผ่าน |
|---|---|---|
| 1 | เลือกหน้าปลายทางที่ต้องการให้คนไปถึง (หน้าเดียว ไม่ใช่หน้าแรก) | ตอบได้ว่า "คนที่ไปถึงหน้านี้แล้วควรทำอะไรต่อ" |
| 2 | ตั้งลิงก์สั้นตามกฎ B2 + ผูก campaign ไม่ซ้ำ | พิมพ์จากมือถือแล้วเข้าถูกหน้า |
| 3 | ใส่ URL สั้นลงในภาพ (ชั้นที่ 2 ของ B4) | อ่านออกจากระยะที่ดู Story จริง |
| 4 | วางลิงก์จริงตามกลไกของแพลตฟอร์ม (ตาราง B1) | กดจากโพสต์จริงแล้วเข้าได้ ทุกแพลตฟอร์มที่โพสต์ |
| 5 | ตรวจ UTM ว่ามาถึงระบบวัดผลจริง | เห็น campaign ในรายงาน หลังมีคนเข้าจริง 1 คน |

## D. กับดักที่คนพลาดบ่อย

- **ทำครีเอทีฟสวยแล้วลืมตั้งไบโอ** — TikTok ได้วิวหลักหมื่นแต่เข้าเว็บ 0 คน เพราะไม่มีทางไปต่อ
  **ตรวจไบโอก่อนโพสต์เสมอ ไม่ใช่หลังโพสต์**
- **ใส่ URL จริงที่ยาวลงในภาพ** — คนอ่านไม่ทัน พิมพ์ผิด แล้วเลิกสนใจ
- **พาไปหน้าแรกแทนหน้าเนื้อหา** — คนมาด้วยความสนใจเรื่องหนึ่ง แล้วต้องหาเองต่อ = หลุด
- **ลิงก์สั้นชี้ไปหน้าที่ถูกลบ/เปลี่ยน slug** — ต้องมีเทสต์ตรวจว่าปลายทางยังมีอยู่จริง
- **path ภาษาไทยไม่ decode ก่อนเทียบ** — เบราว์เซอร์ encode เป็น `%E0%B8…` เสมอ
  ถ้าเทียบกับคีย์ไทยตรง ๆ ลิงก์ไทยจะพังเงียบทุกตัว (พังแบบไม่มี error ให้เห็น)
- **campaign ซ้ำกันหลายคอนเทนต์** — วัดผลไปก็แยกไม่ออกว่าชิ้นไหนได้ผล

## E. Checklist ก่อนโพสต์

- [ ] ปลายทางเป็น **หน้าเนื้อหาเฉพาะ** ไม่ใช่หน้าแรก
- [ ] ลิงก์สั้น ≤ 12 ตัว · มีทั้งไทยและอังกฤษ · เดาได้จากเนื้อหา
- [ ] เปิดลิงก์สั้นจากมือถือจริงแล้วเข้าถูกหน้า (ไม่ใช่แค่ในเครื่อง dev)
- [ ] URL ปรากฏในภาพ อ่านออกจากระยะที่ดูจริง
- [ ] วางลิงก์ตามกลไกของแพลตฟอร์มที่จะโพสต์ครบทุกที่
- [ ] **ถ้าโพสต์ TikTok/Reels — ตั้งไบโอแล้ว**
- [ ] UTM campaign ไม่ซ้ำกับคอนเทนต์ชิ้นอื่น
- [ ] มีคนทดสอบพิมพ์ตามจากภาพ (ไม่ใช่ copy-paste) แล้วเข้าถูก

## F. บทเรียนจากหน้างานจริง

**เคส: ครีเอทีฟพร้อม แต่ traffic เป็นศูนย์**

- **สถานการณ์ก่อน:** ทำครีเอทีฟ 9 ชิ้นเสร็จสวยงาม มีปุ่ม CTA ชัดเจนทุกชิ้น
  คลิปบนแพลตฟอร์มหนึ่งได้วิวเกือบสองหมื่น
- **สิ่งที่คนทั่วไปจะคิด:** "ครีเอทีฟไม่ดีพอ ต้องทำใหม่ให้ดึงดูดกว่านี้"
- **สิ่งที่เป็นจริง:** ครีเอทีฟไม่ใช่ปัญหาเลย — **ไม่มีทางให้คนเดินต่อ** ต่างหาก
  ปุ่มในภาพกดไม่ได้ ไบโอยังไม่ได้ตั้ง และ URL ในภาพยาวเกินกว่าจะพิมพ์ตาม
  ทั้งสามอย่างนี้ทำให้คนที่สนใจจริงก็ไปต่อไม่ได้อยู่ดี
- **บทเรียนที่ทำซ้ำได้:** เมื่อ reach มีแต่ traffic ไม่มี
  **อย่าเพิ่งโทษครีเอทีฟ — ไล่ "ทางเดิน" ตั้งแต่สายตาจนถึงหน้าเว็บก่อน**
  ทุกครั้งที่มีจุดขาดในทางเดิน คนจะหายไปทั้งหมดที่จุดนั้น ไม่ว่าคอนเทนต์จะดีแค่ไหน
