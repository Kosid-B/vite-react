# ขนาด vs ความยืดหยุ่น — ตัดสินใจว่าจะโตทางไหน

> **ใช้ก่อน** ตัดสินใจขยายกำลังผลิต · ซื้อเครื่องจักรใหญ่ · เพิ่ม SKU · รับงาน OEM ล็อตใหญ่
> **และใช้ทันที** เมื่อโรงงานเดินเต็มกำลังแต่กำไรไม่ขึ้น หรือสต็อกโตเร็วกว่ายอดขาย

---

## A. หลักการหลัก (Core Principles)

1. **Economies of scale ไม่ได้ตาย — แต่ "จุดคุ้มทุนขั้นต่ำ" เลื่อนลงมาต่ำกว่าเดิมมาก**
   เดิมต้องผลิตหลักแสนชิ้นถึงจะได้ต้นทุนต่อหน่วยที่แข่งได้
   วันนี้เครื่องจักรที่ตั้งโปรแกรมได้ ระบบวัดผลราคาถูก และซัพพลายเออร์ที่รับงานล็อตเล็ก
   ทำให้โรงเล็กเข้าใกล้ต้นทุนต่อหน่วยของโรงใหญ่ได้เร็วขึ้นมาก
   → **ส่วนต่างต้นทุนที่โรงใหญ่เคยได้เปรียบ แคบลงจนไม่พอชดเชยข้อเสียอื่น**

2. **"ต้นทุนต่อหน่วยที่ถูกที่สุด" ไม่ใช่ตัวเลขที่ควรใช้ตัดสินใจ**
   ตัวเลขที่ใช้ได้จริงคือ **ต้นทุนต่อหน่วยที่ขายได้จริง** — ซึ่งรวมของที่ผลิตแล้วขายไม่ออก
   โรงใหญ่ได้ต้นทุนต่อหน่วยถูกกว่าบนกระดาษ แต่ถ้าต้องลดราคาล้างสต็อก 20% เพื่อระบายของ
   ความได้เปรียบนั้นหายไปหมดและติดลบ (ดู B1)

3. **วงจรชีวิตสินค้าสั้นลง → ความสามารถในการเปลี่ยนไลน์มีค่ามากกว่าเดิม**
   เมื่อสินค้าอยู่ในตลาดสั้นลง เวลาที่ใช้ "เปลี่ยนไปทำของใหม่" กลายเป็นข้อจำกัดหลัก
   ไม่ใช่ "ผลิตของเดิมได้ถูกแค่ไหน"
   โรงที่เปลี่ยนไลน์ได้ใน 2 ชั่วโมง ทดลองตลาดได้ 20 ครั้งต่อปี
   โรงที่ใช้ 3 วัน ทดลองได้ 6 ครั้ง — **ความถี่ในการเรียนรู้ต่างกัน 3 เท่า**

4. **ขนาดใหญ่แปลงต้นทุนคงที่เป็นความเสี่ยง**
   เครื่องจักรเฉพาะทางที่ใหญ่และแพง = เดิมพันว่าดีมานด์รูปแบบนี้จะอยู่นานพอ
   ถ้าตลาดเปลี่ยนก่อนคืนทุน สินทรัพย์นั้นกลายเป็นภาระที่บังคับให้ต้องผลิตของที่ตลาดไม่ต้องการ
   → **ยิ่งลงทุนใหญ่ ยิ่งเปลี่ยนใจยาก และการเปลี่ยนใจไม่ได้คือความเสี่ยงที่แท้จริง**

5. **โรงเล็กไม่ได้ชนะอัตโนมัติ — ที่ชนะคือ "โรงที่เปลี่ยนไลน์เร็ว"**
   โรงเล็กที่ใช้เวลาเปลี่ยนไลน์นานเท่าโรงใหญ่ คือสถานะที่แย่ที่สุด:
   ไม่ได้เปรียบเรื่องต้นทุน และไม่ได้เปรียบเรื่องความเร็ว
   **ตัวแปรจริงคือเวลาเปลี่ยนไลน์ ไม่ใช่ขนาดโรง**

## B. เครื่องมือ (Tools)

### B1. สมการที่ควรใช้แทน "ต้นทุนต่อหน่วย"

```
ต้นทุนต่อหน่วยที่ขายได้จริง =
    ( ต้นทุนผลิตรวม
    + ต้นทุนถือครองสต็อก        ← ดอกเบี้ย พื้นที่ ประกัน ของเสื่อมสภาพ
    + ส่วนลดที่ต้องให้เพื่อระบาย  ← ล้างสต็อกปลายฤดู/ปลายรุ่น
    + มูลค่าของที่ตัดขาดทุนทิ้ง )
    ÷ จำนวนที่ขายได้จริง         ← ไม่ใช่จำนวนที่ผลิตได้
```

**ตัวอย่างเปรียบเทียบ (ตัวเลขสมมติเพื่อแสดงกลไก ไม่ใช่ข้อมูลจริง):**

| | โรงใหญ่ ผลิต 100,000 | โรงยืดหยุ่น ผลิต 30,000 |
|---|---|---|
| ต้นทุนผลิตต่อหน่วย | ฿100 | ฿112 |
| ขายได้จริง | 70,000 (70%) | 29,000 (97%) |
| ต้องลดราคาระบาย | 20,000 ชิ้น × ฿30 | 500 ชิ้น × ฿30 |
| ตัดทิ้ง | 10,000 ชิ้น | 500 ชิ้น |
| **ต้นทุนต่อหน่วยที่ขายได้จริง** | **฿160** | **฿117** |

โรงใหญ่ถูกกว่า 12% บนกระดาษ แต่แพงกว่า 37% เมื่อคิดจากของที่ขายได้จริง
**นี่คือช่องว่างที่รายงานต้นทุนมาตรฐานมองไม่เห็น เพราะมันหารด้วยจำนวนที่ผลิต ไม่ใช่จำนวนที่ขาย**

### B2. เวลาเปลี่ยนไลน์กำหนดทุกอย่าง

ขนาดล็อตที่คุ้มทุนไม่ใช่ค่าคงที่ของโรงงาน — มันเป็น**ผลลัพธ์ของเวลาเปลี่ยนไลน์**

```
เปลี่ยนไลน์ 8 ชม.  → ล็อตต้องใหญ่ถึงจะคุ้ม → ผลิตเผื่อ → สต็อกโต → ของตายเยอะ
เปลี่ยนไลน์ 30 นาที → ล็อตเล็กก็คุ้ม        → ผลิตตามออเดอร์ → สต็อกต่ำ → ของตายน้อย
```

**ลดเวลาเปลี่ยนไลน์ลงครึ่งหนึ่ง = เปลี่ยนโครงสร้างธุรกิจ ไม่ใช่แค่ปรับปรุงประสิทธิภาพ**
เพราะมันย้ายจุดคุ้มทุนของล็อตลงมา ทำให้รับงานที่เมื่อก่อนปฏิเสธได้

วิธีลดที่ทำได้โดยไม่ต้องซื้อเครื่องใหม่ (แนวคิด SMED):
- แยกงานที่ทำได้ "ขณะเครื่องยังเดิน" ออกจากงานที่ต้องหยุดเครื่องทำ
- เตรียมแม่พิมพ์/อุปกรณ์/วัตถุดิบให้พร้อมข้างเครื่องก่อนถึงเวลาเปลี่ยน
- ทำอุปกรณ์จับยึดให้เป็นมาตรฐานเดียวกัน ลดการปรับตั้งด้วยมือ
- เขียนขั้นตอนเปลี่ยนไลน์เป็นเช็กลิสต์ ไม่ใช่ให้ช่างแต่ละคนจำเอง

> ส่วนใหญ่ลดได้ 30–50% โดยไม่ลงทุนอะไรเลย เพราะเวลาที่เสียจริงคือ "หาของ รอของ ลองปรับ"
> ไม่ใช่เวลาที่ใช้เปลี่ยนตัวเครื่อง — **วัดจริงก่อนเชื่อตัวเลขในหัว**

### B3. ตารางวินิจฉัย — ควรโตด้วยขนาด หรือด้วยความยืดหยุ่น

ให้คะแนนข้อละ 1 ตามที่ตรงกับธุรกิจ

| # | คำถาม | ตอบ "ใช่" = ไปทางขนาด | ตอบ "ใช่" = ไปทางยืดหยุ่น |
|---|---|---|---|
| 1 | สินค้าเป็นมาตรฐานตายตัว ลูกค้าไม่ขอปรับ | ✓ | |
| 2 | ลูกค้าขอปรับสูตร/ขนาด/แพ็กบ่อย | | ✓ |
| 3 | ดีมานด์นิ่ง คาดการณ์ล่วงหน้า 6 เดือนได้แม่น | ✓ | |
| 4 | ยอดสั่งแกว่งแรง หรือมาเป็นออเดอร์เล็กหลายราย | | ✓ |
| 5 | สินค้าอยู่ในตลาดได้เกิน 3 ปีโดยไม่ต้องเปลี่ยน | ✓ | |
| 6 | ต้องออกของใหม่ทุกปีเพื่อไม่ให้ตกกระแส | | ✓ |
| 7 | แข่งกันที่ราคาล้วน ลูกค้าเทียบเป็นบาทต่อหน่วย | ✓ | |
| 8 | ลูกค้ายอมจ่ายเพิ่มเพื่อความเร็ว/ความเฉพาะ | | ✓ |
| 9 | การเปลี่ยนไลน์แพงมากโดยธรรมชาติของกระบวนการ | ✓ | |
| 10 | มีสินค้าที่ขายไม่ออกค้างเกิน 90 วัน เกิน 15% ของสต็อก | | ✓ |

**อ่านผล:** ฝั่งไหนได้คะแนนมากกว่า 2 ขึ้นไป = ทางนั้น · ต่างกัน ≤1 = อยู่ในโซนที่ต้องแยกสองสายในโรงเดียว (ดู B5)

### B4. ตัวชี้วัด 5 ตัวที่ต้องเก็บ (ส่วนใหญ่ไม่มีใครเก็บ)

| ตัวชี้วัด | บอกอะไร | เก็บยังไง |
|---|---|---|
| เวลาเปลี่ยนไลน์เฉลี่ย (นาที) | ความยืดหยุ่นจริง | จับเวลาจริง 5 ครั้ง อย่าใช้ตัวเลขในใบสเปก |
| สัดส่วน SKU ที่ขายได้จริง / SKU ทั้งหมด | ความแม่นของการวางแผน | จากยอดขาย 12 เดือน |
| % สต็อกค้างเกิน 90 วัน | ต้นทุนซ่อนที่กำลังโต | จากอายุสต็อก |
| Lead time จากรับออเดอร์ถึงส่งมอบ | สิ่งที่ลูกค้ารู้สึกจริง | นับวันปฏิทิน ไม่ใช่วันทำงาน |
| % รายได้จากสินค้าที่ออกใหม่ใน 12 เดือน | ความสามารถในการต่ออายุตัวเอง | จากบัญชีรายได้ |

**ถ้ายังไม่มีตัวเลข 5 ตัวนี้ อย่าเพิ่งตัดสินใจลงทุนขยายกำลังผลิต**
เพราะการตัดสินใจจะอิงความรู้สึกว่า "ออเดอร์เยอะ" ซึ่งไม่บอกว่ากำไรจะตามมาไหม

### B5. เส้นทางปรับตัวสำหรับโรงที่ใหญ่ไปแล้ว (ไม่ใช่ให้ทุบทิ้ง)

| แนวทาง | ทำอะไร | เหมาะเมื่อ |
|---|---|---|
| **แยกสองสาย** | ไลน์ฐานผลิตของขายประจำแบบเดิม + ไลน์เร็วเล็ก ๆ รับงานเฉพาะ/ทดลอง | มีของขายประจำที่ดีมานด์นิ่งอยู่แล้ว |
| **ผลิตกึ่งสำเร็จรูป** | ทำถึงขั้นกลางเป็นล็อตใหญ่ (ได้ scale) แล้วจบงานตามออเดอร์ (ได้ scope) | ความต่างของสินค้าอยู่ที่ขั้นท้าย เช่น แพ็ก ฉลาก รส สี |
| **รับงานคนอื่นในเวลาว่าง** | ขายกำลังผลิตที่เหลือให้แบรนด์เล็ก | เดินไม่เต็มกำลังอยู่แล้ว และมีเวลาเปลี่ยนไลน์ที่รับได้ |
| **จ้างผลิตส่วนที่เล็ก** | เก็บของหลักไว้ทำเอง ส่งงานล็อตเล็กออกไปข้างนอก | ยังไม่พร้อมลงทุนไลน์เร็ว แต่ต้องรักษาลูกค้าที่ขอของเฉพาะ |

> **ทางที่ปลอดภัยที่สุดคือ "ผลิตกึ่งสำเร็จรูป"** — ได้ทั้งสองอย่างโดยไม่ต้องเลือกข้าง
> และไม่ต้องทิ้งเครื่องจักรที่ลงทุนไปแล้ว

## C. Playbook 6 ขั้น

| ขั้น | ทำอะไร | รู้ได้ยังไงว่าผ่าน |
|---|---|---|
| 1 | วัดตัวชี้วัด B4 ทั้ง 5 ตัวจากของจริง | มีตัวเลขจริงครบ ไม่ใช่ตัวเลขประมาณ |
| 2 | คำนวณต้นทุนต่อหน่วยที่ขายได้จริง (B1) เทียบกับต้นทุนที่ใช้ตั้งราคาอยู่ | รู้ว่าห่างกันกี่ % |
| 3 | ให้คะแนนตาราง B3 | ตอบได้ว่าธุรกิจอยู่ฝั่งไหน หรืออยู่ตรงกลาง |
| 4 | วัดเวลาเปลี่ยนไลน์จริง แล้วหาว่าเสียเวลาไปกับอะไร | แยกได้ว่าส่วนไหนคือ "หาของ/รอของ" ส่วนไหนคือเวลาเครื่องจริง |
| 5 | ลดเวลาเปลี่ยนไลน์ก่อนตัดสินใจลงทุน | ลดได้จริงกี่ % · จุดคุ้มทุนของล็อตเลื่อนลงมาเท่าไร |
| 6 | ค่อยตัดสินใจเรื่องกำลังผลิต ด้วยตัวเลขใหม่ | ตัดสินใจจากต้นทุนต่อหน่วยที่ขายได้จริง ไม่ใช่ต้นทุนผลิต |

> **ขั้น 5 ต้องมาก่อนขั้น 6 เสมอ** — เพราะการลดเวลาเปลี่ยนไลน์มักทำให้กำลังผลิตที่มีอยู่พอใช้
> โดยไม่ต้องลงทุนเพิ่มเลย · หลายโรงซื้อเครื่องใหม่เพื่อแก้ปัญหาที่แก้ได้ด้วยการจัดขั้นตอน

## D. เมื่อไหร่หลักนี้ "ไม่จริง" — อ่านก่อนใช้

หลักนี้เป็นกรอบตัดสินใจ ไม่ใช่คำทำนายว่าโรงงานใหญ่จะหายไป **ขนาดยังชนะชัดเจน**
ในบริบทเหล่านี้ และการฝืนใช้ความยืดหยุ่นตรงนี้คือการเผาเงิน:

| บริบท | ทำไมขนาดยังชนะ |
|---|---|
| สินค้าโภคภัณฑ์ที่แข่งด้วยราคาล้วน (ปูน เหล็ก เคมีพื้นฐาน น้ำตาล) | สเปกตายตัว ลูกค้าไม่ขอปรับ · ต้นทุนต่อหน่วยคือสนามแข่งจริง |
| กระบวนการต่อเนื่องที่หยุดเครื่องแพงมาก (โรงกลั่น เตาหลอม) | การเปลี่ยนไลน์แพงโดยธรรมชาติ ไม่ใช่เพราะจัดการไม่ดี |
| อุตสาหกรรมที่ต้นทุนวิจัย/เครื่องมือสูงมหาศาล (เซมิคอนดักเตอร์ ศูนย์ข้อมูล) | ยิ่งใหญ่ยิ่งได้เปรียบชัด — และกำลังใหญ่ขึ้นเรื่อย ๆ สวนทางกับหลักนี้ |
| สินค้าที่กฎหมายบังคับให้ทุกล็อตต้องผ่านการรับรอง | ต้นทุนการรับรองต่อล็อตสูง ทำให้ล็อตเล็กไม่คุ้ม |

**วิธีใช้อย่างซื่อสัตย์:** ถ้าธุรกิจอยู่ในสี่ข้อข้างบน ให้บอกตรง ๆ ว่าหลักนี้ใช้ไม่ได้
แล้วไปโฟกัสที่การลดต้นทุนต่อหน่วยแทน — **การยัดกรอบที่ไม่เข้ากับหน้างาน
เสียหายกว่าการไม่มีกรอบเลย**

## E. กับดักที่คนพลาดบ่อย

- **คิดว่า "เล็ก" = ยืดหยุ่น** — โรงเล็กที่เปลี่ยนไลน์ช้าเท่าโรงใหญ่ คือแย่ที่สุดในทุกทาง
  ต้องวัดเวลาเปลี่ยนไลน์จริง ไม่ใช่ดูจากขนาด
- **เพิ่ม SKU โดยไม่ลดเวลาเปลี่ยนไลน์ก่อน** — ได้ความหลากหลายมาพร้อมต้นทุนที่ควบคุมไม่ได้
  และมักจบด้วยสต็อกท่วมกับของตายเพิ่ม **ลดเวลาเปลี่ยนไลน์ก่อน แล้วค่อยเพิ่ม SKU**
- **ใช้ต้นทุนต่อหน่วยจากรายงานบัญชีมาตัดสินใจ** — รายงานหารด้วยจำนวนที่ผลิต
  ไม่ใช่จำนวนที่ขายได้ · ยิ่งผลิตเยอะตัวเลขยิ่งสวย ทั้งที่ของกำลังกองอยู่
- **ตัดสินใจตอนออเดอร์เยอะ** — ช่วงออเดอร์ล้นคือช่วงที่ตัดสินใจแย่ที่สุด
  เพราะทุกอย่างดูเหมือนต้องขยาย · ควรตัดสินใจจากตัวเลข 12 เดือน ไม่ใช่จากเดือนที่ยุ่งที่สุด
- **ลงทุนเครื่องเฉพาะทางเพื่อลูกค้ารายเดียว** — กลายเป็นสินทรัพย์ที่ผูกชะตากับลูกค้ารายนั้น
  ถ้าจำเป็นต้องทำ ให้ผูกไว้ในสัญญาว่ารับซื้อขั้นต่ำเท่าไร ไม่ใช่รับปากด้วยวาจา
- **วัดความสำเร็จด้วยอัตราการใช้กำลังผลิต (utilization)** — ตัวเลขนี้สูงได้ด้วยการผลิตของที่ขายไม่ออก
  **ควรวัดด้วยของที่ส่งมอบและเก็บเงินได้แทน**

## G. บทเรียนจากหน้างานจริง

**เคส: เดินเครื่องเต็มกำลัง แต่กำไรไม่ขึ้น**

- **สถานการณ์ก่อน:** โรงงานเดินเกือบเต็มกำลัง อัตราการใช้เครื่องสูง ทุกคนยุ่งทั้งวัน
  ผู้บริหารกำลังพิจารณาลงทุนขยายไลน์เพราะ "ของไม่พอขาย"
- **สิ่งที่คนทั่วไปจะคิด:** ออเดอร์ล้น = ถึงเวลาขยาย
- **สิ่งที่เป็นจริง:** ของที่ผลิตออกมา ส่วนหนึ่งไปกองอยู่ในคลังเพราะผลิตเผื่อตามขนาดล็อตที่
  "ต้องใหญ่ถึงจะคุ้ม" ซึ่งขนาดล็อตนั้นถูกกำหนดโดยเวลาเปลี่ยนไลน์ที่ไม่มีใครเคยจับเวลาจริง
  ตัวเลขอัตราการใช้เครื่องสูงจึงไม่ได้แปลว่าขายได้ดี — แปลว่าเครื่องเดินตลอดเท่านั้น
- **บทเรียนที่ทำซ้ำได้:** เมื่อโรงงานยุ่งแต่กำไรไม่ขึ้น
  **อย่าเพิ่งเพิ่มกำลังผลิต — ไปดูก่อนว่าของที่ผลิตออกมาขายได้กี่เปอร์เซ็นต์**
  ตัวเลขที่หลอกที่สุดในโรงงานคืออัตราการใช้กำลังผลิต เพราะมันสูงได้ด้วยการผลิตของที่ไม่มีคนซื้อ

**เคส: ตัวแปรที่ไม่มีใครวัด**

- **สถานการณ์ก่อน:** ทีมเถียงกันว่าควรซื้อเครื่องใหญ่กว่าเดิมหรือเครื่องเล็กเพิ่มอีกตัว
  ทั้งสองฝ่ายมีเหตุผลและตัวเลขสนับสนุน
- **สิ่งที่เป็นจริง:** ไม่มีใครในห้องรู้ว่าเวลาเปลี่ยนไลน์จริงเท่าไร ทุกคนใช้ตัวเลขที่ "จำกันมา"
  พอไปจับเวลาจริง พบว่าเวลาส่วนใหญ่หมดไปกับการหาอุปกรณ์และรออนุมัติ ไม่ใช่การเปลี่ยนเครื่อง
  ซึ่งแก้ได้โดยไม่ต้องซื้ออะไรเลย และหลังแก้แล้ว กำลังผลิตที่มีอยู่ก็เพียงพอ
- **บทเรียนที่ทำซ้ำได้:** **การถกเถียงเรื่องลงทุนที่ยืดเยื้อ มักเป็นสัญญาณว่าขาดตัวเลขหนึ่งตัว
  ไม่ใช่ขาดความเห็น** — หาให้เจอว่าตัวเลขไหน แล้ววัดมันก่อนประชุมรอบหน้า
