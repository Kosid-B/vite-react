# คำสั่งปฏิบัติงานการตลาด — CEO AI Thailand

> ตั้งขึ้น 22 ส.ค. 2569 · แหล่งเนื้อหาแบรนด์ = [`src/lib/brandBrief.ts`](../../../src/lib/brandBrief.ts)
> **ไฟล์นี้ไม่เขียนกฎซ้ำกับ skill อื่น** — skill อื่นคุม "กฎรายข้อ" · ไฟล์นี้คุม **"ลำดับ"** และ **"วันนี้ทำอะไร"**

## 0️⃣ ก่อนทำอะไรก็ตาม — ตรวจเฟสก่อนเสมอ (ห้ามข้าม)

```
npm run dev  →  แอดมิน → แท็บเวิร์กสเปซ → แผง 🎯 "ถึงเวลาของงานไหนแล้ว"
```
หรืออ่านจากโค้ด: `stageFit.stageFitReport()` · เกณฑ์อยู่ใน `src/lib/stageFit.ts`

**เฟสเปลี่ยน = คำสั่งทั้งแผ่นนี้เปลี่ยน** · ถ้าไม่ตรวจแล้วทำตามข้างล่างเฉย ๆ = ทำงานผิดเฟส

🔴 **เฟสปัจจุบัน (22 ส.ค. 2569): `reach` — ยังไม่มีคนมา**
คำถามเดียวที่มีความหมาย: **"ทำยังไงให้มีคนมาถึงเรา"**

## 1️⃣ 🔴 กฎแม่ — คิดจาก Demand ไม่ใช่จาก "เรามีเท่าไร"

> **"เรามีเท่าไร" จำกัดสิ่งที่พูดได้ · "ตลาดมีเท่าไร" กำหนดสิ่งที่ทำ**
> ห้ามเอาข้อแรกมาตัดสินใจแทนข้อหลัง

**ลูกค้าจ่ายเงิน 0 ราย = ข้อเท็จจริงเกี่ยวกับตัวเรา ไม่ใช่เกี่ยวกับตลาด**
เงินในตลาดเคลื่อนอยู่หรือไม่ ไม่ได้ขึ้นกับว่าเราจับได้หรือยัง

### Demand ที่พิสูจน์แล้ว (เปิด `docs/marketing/MARKET-SIZING-2026.md` อ่านก่อนวางแผนทุกครั้ง)

| | |
|---|---|
| SME ที่ยุ่งกับ ISO/PDPA/มอก. จริง | **50,000–100,000 ราย** |
| มูลค่าเฉพาะหัวหอก compliance | **฿750–1,500 ล้าน/ปี** |
| 🔴 ทำไม WTP สูง | **ทุกวันนี้เขาจ่ายที่ปรึกษาหลักหมื่น–แสน/โปรเจกต์อยู่แล้ว** |
| หลักฐานที่แข็งที่สุด | **B.Training เก็บเงินจากงานนี้มา 20+ ปี** |

⇒ เราไม่ได้ขอให้ใครเริ่มจ่ายในเรื่องที่ไม่เคยจ่าย — **เราขอให้เขาจ่ายน้อยลงสำหรับเรื่องที่จ่ายอยู่แล้ว**

### 🔴 ลำดับของสาร — "ธุรกิจ" นำ · "ISO" ตาม (เจ้าของยืนยัน 22 ส.ค. 2569)

> CEO AI Thailand **สร้างมาสำหรับคนทำธุรกิจ** — compliance เป็นฟีเจอร์เสริม ไม่ใช่ตัวสินค้า

**นี่ไม่ใช่เรื่องรสนิยม — มี 3 เหตุผลที่หนักกว่านั้น** (แหล่ง: `brandBrief.MESSAGE_HIERARCHY`)

| # | เหตุผล |
|---|---|
| ① | ผลิตภัณฑ์คือ **ระบบสร้างและเดินธุรกิจ** · นำด้วย ISO = สัญญาสิ่งที่ไม่ใช่แก่นของเรา |
| ② | 🔴 **นำด้วย ISO = แข่งกับบริษัทแม่ตัวเอง** — B.Training ขายที่ปรึกษา ISO **฿50,000–85,000/โปรเจกต์** · ถ้าเราขึ้นหน้าว่า "ระบบ ISO ฿1,490/เดือน" คนที่กำลังจะจ้างที่ปรึกษาจะเลือกของถูก ⇒ **เสียรายได้หลักหมื่น เพื่อได้ค่าสมาชิกหลักพัน** |
| ③ | **ตลาดต่างกัน ~30 เท่า** — กลุ่มยุ่งกับ ISO จริง 50,000–100,000 ราย vs เจ้าของธุรกิจ ~3.2 ล้านราย ⇒ นำด้วย ISO = ตัดตลาดตัวเองทิ้ง 97% |

⚠️ **ไม่ได้แปลว่าห้ามพูดคำว่า ISO** — คนที่ **พิมพ์คำนั้นค้นหาเอง** ยังต้องเจอเรา (`seg=audit`)
แต่นั่นคือ **ประตูข้าง** ไม่ใช่ **ป้ายหน้าร้าน**

### 🎯 กลุ่มที่มีทริกเกอร์ = ประตูข้าง (ไม่ใช่สารหลัก)

| ✅ กลุ่มที่ demand มีอยู่แล้ว (รับไว้ ไม่ต้องไล่ตาม) | สารหลักยังพูดกับใคร |
|---|---|
| มี **วันตรวจ/audit** รออยู่ · ต่ออายุ cert · โดน PDPA กดดัน | **เจ้าของธุรกิจทั่วไป** — รู้ต้นทุน ตั้งราคา วางระบบ |
| **ค้นหาอยู่แล้ว** ⇒ ทำ `seg=audit` ให้รับเขาได้ | ต้องกระตุ้นให้รู้ตัวก่อน แต่**ตลาดใหญ่กว่า 30 เท่า** |

⇒ **รับกลุ่มทริกเกอร์ = งานที่ทำครั้งเดียว (ประตูเปิดแล้ว)** · **สารหลัก = งานที่ทำทุกวัน**

### พูดอะไรขึ้นหน้า — ขึ้นกับว่าคุยกับกลุ่มไหน (ห้ามใช้กฎเดียวกับทุกคน)

| คุยกับ | ขึ้นหน้าด้วย | ห้ามขึ้นหน้าด้วย |
|---|---|---|
| **คนที่มีทริกเกอร์** (audit/cert/PDPA) | **คำที่เขาค้นหาอยู่จริง** — "เตรียม audit ISO 9001" · "PDPA ต้องทำอะไรบ้าง" | คำกว้าง ๆ ที่ไม่ตรงกับที่เขาพิมพ์ |
| **คนทั่วไปที่ยังไม่รู้ตัว** | **ปัญหาของเขา** — ขายดีแต่เงินไม่เหลือ · ตั้งราคาเท่าไรถึงไม่ขาดทุน | ชื่อหมวดหมู่สินค้า · คำว่า ISO |

⚠️ **ไม่มีใครค้นหาคำว่า "AI Business Operating System"** — ข้อนี้จริงกับทั้งสองกลุ่ม
แต่ **"ISO 9001" มีคนค้นหาทุกวัน** ⇒ **ห้ามเหมารวมว่าคำมาตรฐานเป็นคำต้องห้ามเสมอไป**
กฎ *"ห้ามขึ้นต้นด้วยคำว่า ISO"* คือกฎของ **กลุ่มคนเพิ่งเริ่ม** ไม่ใช่กฎของทุกคน

## 2️⃣ ลำดับงานที่ห้ามสลับ

| ลำดับ | งาน | ทำไมต้องมาก่อน |
|---|---|---|
| **①** | **ปล่อยคอนเทนต์ "ธุรกิจ" ที่มีปลายทางจริง** (ต้นทุน · กำไร · ตั้งราคา · หาลูกค้า) | สารหลัก · ตลาดใหญ่สุด · เป็นสิ่งที่ผลิตภัณฑ์เราทำได้จริงที่สุด · ใช้หาสารที่ทำงานก่อนจ่ายเงินขยาย |
| **②** | **อ่านผล Search Console** → คนค้นคำอะไรแล้วเจอเรา | มีข้อมูลรออยู่แล้วตั้งแต่ ~20 ก.ค. · เปลี่ยน "เดา" เป็น "รู้" ได้ทันทีโดยไม่ต้องผลิตอะไรใหม่ |
| **③** | **ปิดการขาย Pilot ฿1,990 กับคนที่มีทริกเกอร์** | รับ demand ที่มีอยู่แล้ว · ปิดด้วยการโทรคุย · **แต่เป็นงานคู่ขนาน ไม่ใช่สารหลักบนเว็บ** |
| **④** | **ยิงแอดงบเล็กใส่คำค้นเรื่องธุรกิจ** | ต้องมีสารจาก ① ก่อน ไม่งั้นจ่ายเงินขยายสารที่ยังไม่รู้ว่าใช้ได้ไหม |

⚠️ **ห้ามสลับ ①②** · และ **ห้ามเอา ③ ขึ้นมาเป็นสารหลักบนหน้าเว็บ** (ดูเหตุผล 3 ข้อด้านบน)

## 3️⃣ กติกาที่ใช้กับทุกชิ้นงาน (ไม่มีข้อยกเว้น)

| กติกา | มาจาก | ตรวจยังไง |
|---|---|---|
| **ต้องมีปลายทางจริงที่มีของ** | skill `content-link-contract` | `contentLinkContract.test.ts` |
| **คำถามมาก่อนลิงก์เสมอ** (ลิงก์ก่อน = โฆษณา) | `videoEndingContract.test.ts` | `videoEnding()` |
| **ลิงก์ต้องติด `seg=` + `utm`** ให้ตรงเรื่อง | skill `dynamic-plg` | `SHORT_LINKS` |
| **ห้ามอ้างสิ่งที่ระบบทำไม่ได้** (9 คำต้องห้าม) | `brandBrief.FORBIDDEN_PHRASES` | `violatesBrand(text)` |
| **ห้ามอ้างจำนวนลูกค้า/รีวิว** | `brandBrief.HONEST_STATE` | `checkVideoScript()` |
| **ห้ามขึ้นต้นด้วยคำว่า ISO กับคนเพิ่งเริ่ม** | `brandBrief.VOICE.dont` | คนอ่าน |

### ก่อนกด "ปล่อย" ทุกชิ้น — เช็ก 4 ข้อ

1. ปลายทางมีของที่สัญญาไว้จริงไหม (เปิดดูเอง ไม่ใช่เชื่อว่ามี)
2. ลิงก์ติด `seg` + `utm` ตรงเรื่องไหม ⇒ ถ้าไม่ติด **จะไม่มีทางรู้ว่าชิ้นนี้ได้ผลไหม**
3. รัน `violatesBrand()` / `checkVideoScript()` แล้วผ่านไหม
4. ปิดท้ายด้วย **คำถามที่เขาตอบเองไม่ได้ถ้าไม่รู้ตัวเลขของตัวเอง** ใช่ไหม

## 4️⃣ ทำคลิป — ใช้ `src/lib/videoBrief.ts` ห้ามเขียนโครงเอง

```ts
videoScriptPrompt(topic)   // Brand Brief + โครง + ข้อห้าม + ตอนจบ → วางใน AI ตัวไหนก็ได้
checkVideoScript(script)   // ตรวจก่อนถ่าย
```

**หน้าที่ของคลิป**: ทำให้เขารู้ตัวว่า **"ไม่รู้ตัวเลขของตัวเอง"** — ไม่ใช่อธิบายว่าเราขายอะไร

⚠️ **หลักฐานที่ใช้ได้เมื่อเรามีลูกค้า 0 ราย**: โชว์เครื่องมือคำนวณ**สด ๆ** · เครดิต B.Training 20+ ปี ·
ตัวเลขที่ผู้ชมกรอกเอง — **ห้ามใช้รีวิว/จำนวนผู้ใช้/เคสความสำเร็จ** (ยังไม่มี = ทำตอนนี้คือของปลอม)

หัวข้อที่พร้อมถ่ายทันที (มีปลายทางจริงแล้ว): `/ราคา` · `/ทุน` · `/ลูกค้า` · `/ปาล์ม`

## 5️⃣ ยิงแอด — เป็นเครื่องมือ "ซื้อคำตอบ" ไม่ใช่ "ซื้อยอดขาย"

| | ต้องเป็นแบบนี้ |
|---|---|
| ปลายทาง | **เครื่องคำนวณ** (ฟรี ไม่ต้องสมัคร) — แรงเสียดทานต่ำสุดที่มี |
| สาร | **ปัญหา** ไม่ใช่หมวดหมู่สินค้า · ทดสอบ **≥ 2 แบบพร้อมกัน** |
| ตัวชี้วัด | **จำนวนคนกรอกเครื่องคำนวณ** — ไม่ใช่ยอดสมัคร (สมัครเกิดน้อยเกินอ่านผล) |
| งบ | ก้อนเล็ก **มีเพดานเขียนไว้ล่วงหน้า** |

**ห้ามดูตัวเลขก่อนครบ 7 วัน** · **ใช้งบครบแล้วได้ 0 คนกรอก = ปัญหาที่สาร ห้ามเพิ่มงบ**
วันสุดท้ายต้อง **บันทึกต้นทุนต่อคนกรอกลงเอกสาร** — ไม่งั้นเสียเงินแล้วไม่ได้อะไรกลับมา

## 6️⃣ อ่านผล — อ่านอะไร และห้ามอ่านอะไร

| ✅ อ่านได้ตอนนี้ | ❌ ยังอ่านไม่ได้ |
|---|---|
| **จำนวนคน** (เข้าเว็บ · กรอกเครื่องคำนวณ · โทรเข้ามา) | **เปอร์เซ็นต์ทุกชนิด** — คนยังไม่ถึง 100 |
| มี/ไม่มีคนมาจากชิ้นงานนั้น | อัตรา conversion · CPA · ROAS |
| เวลาต่อบล็อก (`sections`) | `avg_scroll` ว่า "อ่านไปกี่ %" |

⚠️ **กับดักที่ต้องรู้ก่อนอ่านรายงาน**
- **`direct` ไม่ได้แปลว่าพิมพ์ URL เข้ามาเอง** — คนที่มาจากบทความของเราเองถูกนับเป็น direct ทั้งหมด
- **เครื่องมือที่ "ตั้งไว้แต่ไม่ได้ต่อ" ทำให้ทุกตัวเลขเป็นคำโกหกโดยการละเว้น** ⇒ พิสูจน์ว่าตัววัดทำงานก่อนอ่านผลเสมอ

## 7️⃣ เมื่อไรถึงเปลี่ยนแผน (เกณฑ์ตัวเลข ไม่ใช่ความรู้สึก)

| เจอแบบนี้ | แปลว่า | ทำอะไร |
|---|---|---|
| ผู้เข้าชม < 100 คน/สัปดาห์ | คอขวดคือ **ไม่มีคนมา** | **ห้ามไปแก้หน้าเว็บ** — ไปทำงาน ①②③ (หัวข้อ 2) |
| ปล่อยคอนเทนต์แล้วไม่มีใครเข้ามาจากชิ้นนั้นเลย | ลิงก์ไม่ติด utm **หรือ** สารไม่โดน | ตรวจ utm ก่อน แล้วค่อยโทษสาร |
| คนเข้าเว็บเพิ่ม แต่ไม่มีใครกรอกเครื่องคำนวณ | พามาผิดคน **หรือ** ปลายทางไม่ตรงกับที่สัญญา | เทียบข้อความในชิ้นงานกับหน้าปลายทางทีละบรรทัด |
| มีคนกรอกเครื่องคำนวณ แต่ไม่มีใครสมัคร | **ปกติในเฟสนี้** | อย่าเพิ่งแก้ — ยอดสมัครเกิดน้อยเกินกว่าจะอ่านผล |
| มีคนโทรมาถาม Pilot | 🟢 **สัญญาณที่แรงที่สุดที่เป็นไปได้** | หยุดทุกอย่างแล้วไปคุยให้จบ |

## 8️⃣ ห้ามทำ (พร้อมเหตุผล — ห้ามแปลว่าห้ามคิด)

| 🚫 ห้าม | ทำไม |
|---|---|
| ทำรีวิว/คำชมจากลูกค้า | ลูกค้าจ่ายจริง = 0 ราย ⇒ ทำตอนนี้คือของปลอม |

| ตัดเนื้อหาบนเว็บทิ้งเพราะ "สื่อสารกว้างเกินไป" | 15 จาก 19 บล็อก **ยังไม่เคยมีใครเห็นเลย** — ตัดของที่ยังไม่เคยถูกเห็น = ตัดโดยไม่มีข้อมูล |
| ลอกกลยุทธ์ปลายเกมจากเคสบริษัทยักษ์ | skill `case-study-stage-fit` — "ของดีไม่ต้องโฆษณา" = คำอธิบายของผู้ชนะ ไม่ใช่วิธีชนะ |
| ยิงแอดเพื่อเร่งยอดขาย/เร่งสมัคร | ปลายทางยังพิสูจน์ไม่ได้ว่าเปลี่ยนคนเป็นลูกค้าได้ |

## 9️⃣ ถ้าถามว่า "วันนี้ทำอะไร" — ตอบตามนี้

1. เปิดแผง 🎯 ดูว่าเฟสเปลี่ยนหรือยัง
2. ยังเป็น `reach` ⇒ เลือก **1 อย่าง** จากงาน ①②③ ทำให้จบ
3. ทำเสร็จแล้ว **ตรวจ 4 ข้อก่อนปล่อย** (หัวข้อ 3)
4. บันทึกว่าปล่อยอะไรไปเมื่อไร — ไม่งั้นสัปดาห์หน้าจะอ่านผลไม่ออกว่ามาจากชิ้นไหน

> 🧠 **ประโยคเดียวที่ต้องจำ**: งานตอนนี้ไม่ใช่ "ทำให้คนซื้อ" แต่คือ **"ทำให้มีคนรู้ว่าเรามีอยู่ แล้วพิสูจน์ว่ามีคนยอมจ่าย 1 ราย"**
