# หา Pain / Gain ให้เจอของจริง (ก่อนคิดสินค้า)

> **ใช้ก่อน** ออกแบบสินค้า · เขียนหน้าขาย · ตั้งราคา · ทำคอนเทนต์
> **และใช้ทันที** เมื่อได้ยินประโยคว่า "ของเราดีจริง ๆ นะ แต่ไม่รู้ทำไมขายไม่ออก"

---

## A. หลักการหลัก (Core Principles)

1. **ยุคนี้สินค้าไม่ใช่สิ่งที่ขาดแคลน — ความเข้าใจต่างหากที่ขาด**
   ปัจจัย 4 มีครบและมีทางเลือกล้นตลาด คนไม่ได้รอ "ของอีกชิ้น"
   สิ่งที่ยังหายากคือ **คนที่พูดถูกว่าเขาเจ็บตรงไหน** ใครพูดถูกก่อน คนนั้นได้ความไว้ใจก่อน
   → การหา pain/gain จึงไม่ใช่ขั้นตอนหนึ่งของการตลาด แต่เป็น **งานที่มาก่อนสินค้า**

2. **คนตัดสินใจด้วยอารมณ์ แล้วหาเหตุผลมารองรับทีหลัง**
   สเปก ตาราง และข้อมูลเปรียบเทียบ ไม่ได้ทำให้คนตัดสินใจ
   มันทำหน้าที่ **"อนุญาตให้ตัวเองซื้อได้โดยไม่รู้สึกว่าโง่"** ต่างหาก
   → ข้อความต้องยิงอารมณ์ก่อน แล้วค่อยมีเหตุผลไว้ให้เขาใช้อธิบายกับตัวเองและคนรอบตัว
   → ถ้ามีแต่เหตุผล = ไม่มีใครขยับ · ถ้ามีแต่อารมณ์ = ขยับแล้วเสียดายทีหลัง ต้องมีทั้งคู่ ตามลำดับ

3. **ความเจ็บที่ลูกค้าพูดออกมา ไม่ใช่ความเจ็บจริง**
   สิ่งที่พูดคือ **อาการ** ของจริงอยู่ลึกลงไปอีกสองชั้น (ดู B1)
   คนไม่ได้โกหก แต่คนอธิบายความรู้สึกตัวเองเป็นภาษาที่ฟังดูสมเหตุสมผลเสมอ

4. **ลำดับผิด = ต้องยัดเยียดไปตลอดอายุธุรกิจ**
   สร้างของก่อนแล้วค่อยหาคนที่เจ็บ → ต้องออกแรงโน้มน้าวทุกครั้งที่ขาย
   หาความเจ็บก่อนแล้วค่อยสร้างของ → ลูกค้าเป็นฝ่ายอธิบายให้เราฟังว่าทำไมเขาต้องการ

5. **Gain ที่แรงที่สุดไม่ใช่ผลลัพธ์ แต่คือตัวตนที่อยากเป็น**
   "ประหยัดเวลา 5 ชั่วโมง" เป็นผลลัพธ์
   "เป็นเจ้าของร้านที่คุมธุรกิจตัวเองอยู่ ไม่ใช่ถูกธุรกิจลาก" คือตัวตน
   คนจ่ายแพงให้ตัวตน ไม่ได้จ่ายแพงให้ตัวเลข

6. **เข้าใจอารมณ์ ≠ ได้ใบอนุญาตปั่นอารมณ์**
   ยิ่งเข้าใจความกลัวของคนลึกเท่าไร ยิ่งต้องระวังไม่ใช้มันบีบคน
   เส้นแบ่ง: **ทำให้เขาเห็นปัญหาที่มีอยู่จริงชัดขึ้น = ถูก · สร้างความกลัวที่ไม่มีอยู่จริง = ผิด**
   (ดู E)

## B. เครื่องมือ (Tools)

### B1. บันไดความเจ็บ 3 ชั้น — ขุดให้ถึงชั้นล่างสุดเสมอ

```
ชั้น 1  อาการ        สิ่งที่ลูกค้าพูด            "ทำบัญชีเองมันยุ่งยาก"
   ↓
ชั้น 2  ต้นทุน       สิ่งที่เสียไปจริง วัดได้    เสีย 6 ชม./เดือน · เคยยื่นภาษีผิด
   ↓
ชั้น 3  ความรู้สึก   สิ่งที่กลัว/อาย/เหนื่อย    กลัวโดนเรียกตรวจ · อายที่ดูไม่มืออาชีพ
                                              เหนื่อยที่ต้องเก่งทุกเรื่องคนเดียว
```

| ชั้น | ใช้ทำอะไร |
|---|---|
| 1 | ใช้เป็นคำค้นหา (คนพิมพ์หาด้วยคำชั้นนี้) |
| 2 | ใช้เป็นเหตุผลให้เขาอธิบายการซื้อกับตัวเองและคนรอบตัว |
| 3 | **ใช้เป็นประโยคเปิด** — ชั้นนี้คือชั้นที่ทำให้คนหยุดเลื่อนแล้วคิดว่า "นี่มันเรื่องของฉัน" |

**คนส่วนใหญ่ทำการตลาดที่ชั้น 1 แล้วสงสัยว่าทำไมไม่มีใครสนใจ**

### B2. คำถามขุด 5 ข้อ — และคำถามที่ห้ามถาม

❌ **ห้ามถาม** "อยากได้อะไร" · "ถ้ามีสินค้าแบบนี้จะซื้อไหม" · "คิดว่าราคาเท่าไรเหมาะสม"
คำถามพวกนี้ให้คำตอบที่สุภาพและไร้ประโยชน์ เพราะคนจินตนาการอนาคตตัวเองไม่แม่น

✅ **ถามเรื่องอดีตที่เกิดขึ้นจริงแทน**

| # | คำถาม | ได้อะไร |
|---|---|---|
| 1 | ครั้งล่าสุดที่เจอเรื่องนี้คือเมื่อไร วันนั้นเกิดอะไรขึ้นบ้าง | เรื่องจริง มีวันเวลา ไม่ใช่ความคิดเห็น |
| 2 | ตอนนี้แก้ปัญหานี้ยังไง | เจอ workaround = เจอความเจ็บที่แรงพอให้คนลงแรง |
| 3 | เรื่องนี้ทำให้เสียอะไรไปบ้าง (เวลา เงิน โอกาส) | ชั้น 2 — ต้นทุนที่วัดได้ |
| 4 | เคยจ่ายเงินหรือจ้างใครช่วยเรื่องนี้ไหม เท่าไร | หลักฐานว่ายอมจ่ายจริง ไม่ใช่แค่บ่น |
| 5 | ถ้าเรื่องนี้หายไป วันของคุณจะต่างยังไง แล้วคนอื่นจะเห็นคุณต่างไปไหม | ชั้น 3 + Gain ระดับตัวตน |

> **ข้อ 5 คือคำถามที่คนมักลืมถาม** และเป็นข้อที่ให้ประโยคขายที่ดีที่สุดเสมอ
> ให้เขาพูดจบแล้วเงียบรอ — ประโยคที่สองที่เขาพูดออกมามักจริงกว่าประโยคแรก

### B3. เกณฑ์ 4 ข้อ — พิสูจน์ว่าเจอ "ของจริง" ไม่ใช่คำพูดลอย ๆ

ให้ 1 คะแนนต่อข้อที่ผ่าน:

- [ ] **มี workaround อยู่แล้ว** — เขาลงแรงแก้เองอยู่ทุกวัน (สมุด Excel ให้ญาติช่วย)
- [ ] **เคยจ่าย** — เงิน เวลา หรือคน ให้กับเรื่องนี้มาก่อน
- [ ] **เล่าเรื่องเฉพาะเจาะจงได้** — มีวัน มีเหตุการณ์ ไม่ใช่พูดกว้าง ๆ
- [ ] **มีอารมณ์ปนตอนเล่า** — โมโห อาย กลัว เหนื่อย น้ำเสียงเปลี่ยน

| คะแนน | แปลว่า | ทำต่อ |
|---|---|---|
| 4 | ความเจ็บจริง มีคนยอมจ่าย | เดินหน้าได้ |
| 3 | น่าจะจริง แต่ยังไม่ชัดว่าจ่าย | คุยเพิ่มอีก 3 คน |
| ≤ 2 | ยังเป็นแค่ความคิดเห็น | **อย่าเพิ่งสร้างอะไร** |

**"เขาบอกว่าน่าสนใจมาก" = 0 คะแนน** — ความสุภาพไม่ใช่หลักฐาน

### B4. Gain 3 ระดับ — ไต่ขึ้นให้ถึงระดับ 3

```
ระดับ 1  ผลลัพธ์      "ปิดบัญชีเสร็จใน 10 นาที"
   ↑
ระดับ 2  ความรู้สึก   "ไม่ต้องกลัวว่าตัวเลขจะผิดอีก"
   ↑
ระดับ 3  ตัวตน        "เป็นเจ้าของธุรกิจที่รู้ตัวเลขของตัวเอง คุยกับธนาคารได้อย่างมั่นใจ"
```

ราคาที่ตั้งได้ขึ้นกับระดับที่สื่อสาร — ระดับ 1 ถูกเทียบราคาได้ทันที ระดับ 3 เทียบยาก

### B5. ลำดับการทำงานที่ถูก

```
✅ pain/gain → ข้อความ → ข้อเสนอ → สินค้า → ฟีเจอร์
❌ ฟีเจอร์ → สินค้า → ข้อเสนอ → ข้อความ → ไปหาคนที่น่าจะเจ็บ
```

ทางล่างไม่ได้ผิดเสมอไป — แต่มันแพงกว่ามาก เพราะทุกอย่างที่สร้างไว้แล้วจะกลายเป็นภาระ
ที่ต้องปกป้อง แทนที่จะเป็นเครื่องมือที่ปรับได้

### B6. สูตรแปลง pain → ประโยคที่ใช้ได้จริง

```
[สถานการณ์เฉพาะที่เขาจำได้] + [ต้นทุนที่เสียจริง] + [ความรู้สึกชั้น 3]
```

| ❌ เขียนแบบนี้ | ✅ เขียนแบบนี้ |
|---|---|
| ระบบบัญชีที่ใช้ง่าย ครบวงจร | ขายดีทุกวัน แต่สิ้นเดือนเงินไม่เหลือ — เพราะต้นทุนต่อจานที่ลืมหัก |
| บริการที่ปรึกษามาตรฐาน ISO ครบวงจร | ลูกค้ารายใหญ่ขอเอกสารระบบ แล้วเราหาไม่เจอว่าใครเก็บไว้ |
| แพลตฟอร์มบริหารธุรกิจด้วย AI | ทำเองทุกอย่างจนไม่มีเวลาคิดว่าจะโตยังไง |

**สังเกต:** คอลัมน์ขวาไม่มีคำว่าสินค้าเราอยู่เลยสักคำ — นั่นคือจุดที่ถูกต้อง

## C. Playbook 5 ขั้น

| ขั้น | ทำอะไร | รู้ได้ยังไงว่าผ่าน |
|---|---|---|
| 1 | เลือกกลุ่มคนที่เจาะจงพอจะนัดคุยได้จริง (ไม่ใช่ "SME ไทย") | นึกชื่อคนจริงได้ 5 คนในกลุ่มนั้น |
| 2 | คุย 5–7 คน ด้วยคำถาม B2 · ห้ามเสนอขายระหว่างคุย | ได้เรื่องเล่าเฉพาะเจาะจง ไม่ใช่ความคิดเห็น |
| 3 | ไต่บันได B1 ให้ถึงชั้น 3 ทุกคน แล้วหาคำที่ซ้ำกัน | มีความเจ็บ 1–2 เรื่องที่โผล่ในเกือบทุกบทสนทนา |
| 4 | ให้คะแนน B3 · เก็บเฉพาะเรื่องที่ได้ 3–4 คะแนน | ตัดทิ้งได้อย่างสบายใจ เพราะมีเกณฑ์ ไม่ใช่ความรู้สึก |
| 5 | เขียนประโยคด้วยสูตร B6 แล้วเอาไปทดสอบก่อนสร้างของ | มีคนตอบกลับด้วยคำพูดของเขาเอง ไม่ใช่แค่กดไลก์ |

> **ขั้น 2 ห้ามขาย** — วินาทีที่เริ่มขาย คู่สนทนาจะเปลี่ยนโหมดเป็นสุภาพ และข้อมูลจะเสียทันที

## D. กับดักที่คนพลาดบ่อย

- **หยุดที่ชั้น 1 แล้วคิดว่าหา pain เจอแล้ว** — ได้คำที่ถูกต้องแต่ไม่มีใครรู้สึกอะไร
- **ถามคำถามอนาคต** ("จะซื้อไหม") — ได้คำตอบที่สุภาพและผิดเกือบทุกครั้ง
- **เอาความเจ็บของตัวเองไปสวมให้ลูกค้า** — เจ้าของธุรกิจเจ็บเรื่องที่ลูกค้าไม่ได้เจ็บบ่อยมาก
  โดยเฉพาะคนที่เคยเป็นลูกค้าเองมาก่อน จะมั่นใจเกินหลักฐาน
- **เจอความเจ็บจริงแต่คนกลุ่มนั้นไม่มีเงิน/ไม่มีอำนาจตัดสินใจ** — เจ็บจริงแต่ธุรกิจไม่เกิด
  ต้องเช็กด้วยว่า *คนที่เจ็บ* กับ *คนที่จ่าย* เป็นคนเดียวกันไหม
- **ยิงอารมณ์แล้วไม่มีเหตุผลรองรับ** — คนซื้อแล้วเสียดาย ขอคืน และไม่บอกต่อ
- **สรุปจากคนเดียว** — คนที่พูดเก่งที่สุดมักไม่ใช่คนที่เป็นตัวแทนกลุ่ม
- **สัมภาษณ์เสร็จแล้วสรุปตามที่อยากได้ยิน** — ให้จดคำพูดดิบไว้ก่อน แล้วค่อยตีความทีหลัง

## E. เส้นแบ่งจริยธรรม (สำคัญเมื่อเข้าใจอารมณ์คนลึก)

| ✅ ทำได้ | ❌ ห้ามทำ |
|---|---|
| ทำให้ปัญหาที่มีอยู่จริงชัดขึ้น | สร้างปัญหาที่ไม่มีอยู่จริงขึ้นมาให้กลัว |
| บอกต้นทุนที่เขากำลังจ่ายอยู่โดยไม่รู้ตัว | ขู่ผลลัพธ์เกินจริงว่าจะเสียหายหนัก |
| ใช้เส้นตายที่มีอยู่จริง (กฎหมาย ฤดูกาล) | สร้างความเร่งด่วนปลอม นับถอยหลังหลอก |
| เล่าเรื่องลูกค้าจริงโดยได้รับอนุญาต | แต่งรีวิว แต่งตัวเลข |
| พูดถึงความกลัวที่เขาพูดออกมาเอง | ขุดปมส่วนตัวมาใช้กดดัน |

**เกณฑ์ตัดสินง่าย ๆ:** ถ้าลูกค้ารู้ทีหลังว่าเราคิดแบบนี้ตอนเขียนข้อความนี้
เขาจะรู้สึก *"เข้าใจฉันจัง"* หรือ *"โดนหลอก"* — ถ้าตอบไม่ได้ว่าอย่างแรก อย่าใช้

## F. Checklist ก่อนเริ่มสร้าง / ก่อนเขียนหน้าขาย

- [ ] คุยกับคนจริงอย่างน้อย 5 คน ไม่ใช่เดาจากประสบการณ์ตัวเอง
- [ ] ไต่ถึงชั้น 3 แล้ว (เขียนความรู้สึกออกมาเป็นคำได้)
- [ ] ความเจ็บได้ ≥ 3 คะแนนตามเกณฑ์ B3

## G. บทเรียนจากหน้างานจริง

**เคส: ของดีจริง แต่ไม่มีใครสนใจ**

- **สถานการณ์ก่อน:** ระบบทำมาครบ ฟีเจอร์เยอะ คุณภาพไม่มีปัญหา
  หน้าเว็บอธิบายความสามารถได้ละเอียดทุกข้อ แต่คนเข้ามาแล้วออกภายในไม่กี่วินาที
- **สิ่งที่คนทั่วไปจะคิด:** "ต้องเพิ่มฟีเจอร์อีก" หรือ "ต้องยิงโฆษณาให้คนเห็นเยอะกว่านี้"
- **สิ่งที่เป็นจริง:** ข้อความทั้งหน้าอยู่ที่ **ชั้น 1** ทั้งหมด — บอกว่าระบบทำอะไรได้
  แต่ไม่มีสักบรรทัดที่ทำให้คนอ่านรู้สึกว่า *"นี่มันเรื่องของฉัน"*
  คนที่เจ็บจริงเลื่อนผ่าน เพราะไม่มีอะไรบอกเขาว่าเรารู้ว่าเขาเจ็บอยู่
- **บทเรียนที่ทำซ้ำได้:** เมื่อของดีแต่ขายไม่ออก
  **อย่าเพิ่มของ — ให้ลดระยะห่างระหว่างข้อความกับความรู้สึกของคนอ่านก่อน**
  ฟีเจอร์เพิ่มอีกสิบอย่างก็ยังอยู่ชั้น 1 อยู่ดี และคนก็จะยังเลื่อนผ่านเหมือนเดิม

**เคส: ความเจ็บของเจ้าของ ไม่ใช่ความเจ็บของลูกค้า**

- **สถานการณ์ก่อน:** เจ้าของแก้ปัญหาที่ตัวเองเคยเจอตอนทำธุรกิจ มั่นใจมากว่าคนอื่นต้องเจ็บเหมือนกัน
- **สิ่งที่เป็นจริง:** คนอื่นเจ็บเรื่องนั้นจริง แต่ไม่แรงพอจะจ่าย — เพราะเขามี workaround
  ที่ทนได้อยู่แล้ว ส่วนเรื่องที่เขาเจ็บจนยอมจ่ายกลับเป็นอีกเรื่องที่เจ้าของมองข้าม
  เพราะตัวเองแก้ได้ง่ายจนไม่คิดว่าเป็นปัญหา
- **บทเรียนที่ทำซ้ำได้:** **สิ่งที่เราทำได้ง่ายจนไม่รู้สึกว่ายาก มักเป็นสิ่งที่คนอื่นยอมจ่ายที่สุด**
  ประสบการณ์ 20 ปีทำให้หลายอย่างกลายเป็นเรื่องธรรมดาในสายตาเรา — และนั่นคือจุดบอด
  ไม่ใช่ข้อได้เปรียบ ถ้าไม่ได้ออกไปถามคนจริง
