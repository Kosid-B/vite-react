# สายการผลิต: ข่าว → คอนเทนต์ทุกแพลตฟอร์ม → ปฏิทิน → คลิปสั้น

> **สัญญาของสายนี้:** ส่งข่าวมาหนึ่งชิ้น ได้กลับไปครบชุดในครั้งเดียว
> ไม่ต้องกลับมาถามหาลิงก์ ไม่ต้องประกอบ URL เอง ไม่ต้องเปิดหาไฟล์

---

## A. หลักการหลัก

1. **สรุปข่าวจากผู้ช่วยข่าวคือ "เบาะแส" ไม่ใช่ "แหล่งอ้างอิง"**
   ต้องตามไปหาต้นทางเสมอ — ตัวเลขที่ผิดหรือถูกตีความผิดจะกลายเป็นโพสต์สาธารณะ
   ที่มีชื่อเราอยู่บนนั้น และคนที่ตรวจสอบเป็นคือคนที่เราอยากได้เป็นลูกค้าพอดี

2. **ห้ามหยิบตัวเลขด้านเดียวจากงานวิจัยเดียวกัน**
   งานวิจัยส่วนใหญ่มีตัวเลขที่ขัดแย้งกันเองอยู่ในเล่ม การหยิบเฉพาะตัวที่เข้าทางเรา
   ทำให้พาดหัวขัดกับแหล่งที่เราอ้างเอง — ซึ่งพังทันทีถ้ามีคนเปิดไปดู

3. **ข่าวหมดอายุ แต่บทความไม่หมด**
   คอนเทนต์ข่าวมีค่าไม่กี่วัน ส่วนบทความปลายทางอยู่ได้เป็นปีและถูกค้นเจอเรื่อย ๆ
   → **ทุกครั้งที่ทำคอนเทนต์ข่าว ให้ได้บทความถาวรเพิ่มมาหนึ่งชิ้นเสมอ**

4. **หนึ่งข่าว = อย่างน้อยสองเวอร์ชัน**
   เวอร์ชันมวลชน (reach เยอะ ยังไม่มีเงินจ่าย) และเวอร์ชันคนที่จ่ายได้
   ถ้าทำได้เวอร์ชันเดียว ให้ทำเวอร์ชันหลัง

5. **ส่งมอบต้องพร้อมวาง ไม่ใช่พร้อมแก้**
   ป้ายกำกับภายใน ลิงก์ย่อ ตัวเลือก A/B ที่ยังไม่ตัดสิน — ทั้งหมดนี้คือภาระที่โยนกลับไปให้คนโพสต์

## B. 6 ขั้นของสายการผลิต

### ขั้น 1 — ตรวจข้อเท็จจริงกับต้นทาง

| ทำอะไร | เกณฑ์ผ่าน |
|---|---|
| ค้นหาตัวเลขทุกตัวที่จะใช้ กับแหล่งต้นทาง | ได้ URL ที่กดเข้าไปเห็นตัวเลขนั้นจริง |
| อ่านให้ครบว่ามีตัวเลขอื่นในเล่มที่ขัดกันไหม | ตอบได้ว่าภาพรวมของงานวิจัยพูดว่าอะไร |
| แยก "ข้อเท็จจริง" กับ "การคาดการณ์" | คำว่า *คาดว่า / ประเมินว่า* ต้องคงไว้ |
| ตัวเลขที่หาต้นทางไม่เจอ | **ตัดออก** ไม่ใช่ใส่ไว้ก่อน |

> ถ้าสองหน่วยงานให้ตัวเลขต่างกัน → เลือกใช้ทีละแหล่งพร้อมระบุชื่อ
> **ห้ามเฉลี่ย ห้ามสลับไปมาในโพสต์เดียว** (ดู skill `thai-market-data-sources`)

### ขั้น 2 — ปลายทางก่อนคอนเทนต์

เช็กว่ามีบทความที่ตอบสิ่งที่โพสต์จะสัญญาหรือยัง

- **มีแล้ว** → ใช้เลย (ต้องเปิดอ่านจริง ไม่ใช่ดูจากชื่อเรื่อง)
- **ไม่มี** → **เขียนบทความก่อน** แล้วค่อยส่งพร้อมกันในครั้งเดียว
- ห้ามชี้หน้าแรก ห้ามชี้หน้าสมัคร (ดู skill `content-link-contract`)

### ขั้น 3 — เขียนคอนเทนต์แยกทุกแพลตฟอร์ม

| แพลตฟอร์ม | ความยาว | น้ำเสียง |
|---|---|---|
| Facebook | ยาวได้ มีย่อหน้า | เล่าเรื่อง มีตัวเลขรองรับ |
| LINE | **สั้นกว่า FB ราวครึ่งหนึ่ง** | คุยกับคนรู้จัก ใช้ "เรา" ไม่ใช่ "คุณ" · ไม่ใส่แฮชแท็ก |
| LinkedIn | ยาวได้ | มืออาชีพ เน้นเหตุผลและโครงสร้าง |
| TikTok / Reels | แคปชันสั้น | ชี้ทางไปไบโอเสมอ + คอมเมนต์ปักหมุด |
| YouTube Shorts | ชื่อคลิป = hook · คำอธิบาย = ลิงก์ | ห้ามใส่ลิงก์ในช่องชื่อ |

ทุกเวอร์ชันต้องเปิดที่ **ชั้น 3 (ความรู้สึก)** และอยู่ชั้น 3 ต่อ ไม่ตกกลับไปชั้น 1
(ดู skill `pain-gain-discovery`)

### ขั้น 4 — URL เต็มต่อแพลตฟอร์ม

เขียนเต็มทุกตัว ไม่ย่อ:

```
Facebook   https://ceoaithailand.org/<สั้น>?s=fb&c=<โค้ดชิ้นงาน>
LINE       https://ceoaithailand.org/<สั้น>?s=line&c=<โค้ดชิ้นงาน>
LinkedIn   https://ceoaithailand.org/<สั้น>?s=li&c=<โค้ดชิ้นงาน>
TikTok     https://ceoaithailand.org/<สั้น>?s=tt        ← ใส่ในไบโอ
Instagram  https://ceoaithailand.org/<สั้น>?s=ig
Shorts     https://ceoaithailand.org/<สั้น>?s=yt&c=<โค้ดชิ้นงาน>
ในภาพ/คลิป ceoaithailand.org/<สั้น>                      ← ตัวสั้นเปล่า ให้พิมพ์ตาม
```

**ตรวจก่อนส่ง:** TikTok/Instagram ใช้ลิงก์ไบโอตัวเดียว → ถ้าเรื่องนี้ไม่ตรงกับช่วงไบโอปัจจุบัน
ให้ส่งเฉพาะ Facebook/LINE/LinkedIn ได้ทันที แล้วระบุว่าคลิปต้องรอถึงวันไหน

### ขั้น 5 — ใส่ Google Calendar

| กติกา | เหตุผล |
|---|---|
| **คำอธิบายอีเวนต์ต้องมีข้อความเต็มที่ก๊อปวางได้** | คนโพสต์ไม่ต้องเปิดหาไฟล์ตอนจะโพสต์ |
| แยกบล็อกให้ชัดว่าอันไหนของแพลตฟอร์มไหน | กันวางผิดช่อง |
| โพสต์ตั้งเวลา **19:00** · งานจัดการตั้ง **09:00** | ให้ตรงกับจังหวะที่คนอ่าน |
| ใส่ข้อควรระวังของชิ้นนั้นท้ายอีเวนต์ | เช่น "ห้ามเขียนว่าราคาขึ้นแน่นอน" |
| หนึ่งข่าว = หนึ่งอีเวนต์ต่อหนึ่งเวอร์ชัน | เวอร์ชันมวลชนกับเวอร์ชันคนจ่ายได้ ห่างกันอย่างน้อย 1 วัน |

### ขั้น 6 — ไฟล์ฉากสำหรับคลิปสั้น

สร้างไฟล์ JSON ใน `tools/shortvideo/scenes/` แล้วบอกคำสั่ง 3 บรรทัดที่รันได้เลย
(รายละเอียดใน `tools/shortvideo/README.md`)

**โครงคลิป 15 วินาทีที่ใช้ได้กับข่าวเกือบทุกชิ้น:**

```
0.0–3.6   ชั้น 3 — คำถาม/ประโยคที่ทำให้คนหยุดเลื่อน (ห้ามใส่ตัวเลข ห้ามใส่ชื่อสินค้า)
3.4–8.0   ตัวเลขจากข่าว 1 ตัว ที่ตรวจแหล่งแล้ว + ที่มาเป็นชื่อหน่วยงาน
7.8–12.0  แปลว่าอะไรกับคนดู (ต้นทุนที่เขากำลังจ่ายอยู่โดยไม่รู้ตัว)
11.8–15.0 บอกทางไปต่อ + URL สั้นบนจอ + "อ่านฟรี ไม่ต้องสมัคร"
```

**ข้อบังคับของคลิป:**
- เว้นขอบล่าง ~420px (แพลตฟอร์มวางแคปชัน/ปุ่มทับ)
- URL บนจอใช้ตัวสั้นเปล่า ๆ ห้ามมี `?s=`
- ห้ามใส่ตัวเลขที่ยังไม่ได้ตรวจแหล่ง — **คลิปแก้ย้อนหลังไม่ได้เหมือนแคปชัน**

## C. รูปแบบการส่งมอบ (ทุกครั้งต้องมีครบ)

```
1. สรุปผลตรวจข้อเท็จจริง — ตัวไหนจริง ตัวไหนตัดออก ตัวไหนถูกตีความผิด (+ URL แหล่ง)
2. บทความปลายทาง — ลิงก์ที่เปิดได้จริง (เขียนใหม่ถ้ายังไม่มี)
3. คอนเทนต์แยกแพลตฟอร์ม — แต่ละอันครอบบล็อกโค้ด ก๊อปทั้งบล็อกได้
4. ตาราง URL เต็ม
5. ตารางพิสูจน์ claim ↔ หัวข้อในบทความ
6. รายการ "สิ่งที่ห้ามเขียน" ของชิ้นนี้
7. อีเวนต์ในปฏิทิน — พร้อมข้อความเต็มในคำอธิบาย
8. ไฟล์ฉากคลิป + คำสั่งสร้าง
```

## D. กับดักที่เกิดซ้ำจริงในสายนี้

- **ป้ายกำกับภายในติดไปกับโพสต์** — "ชุดสมรรถนะสูงสุด" "เวอร์ชัน A" "🏆 กระทบใจลึกที่สุด"
  ที่ใส่ไว้ให้ทีมดู กลายเป็นบรรทัดแรกของโพสต์สาธารณะ
  **แก้:** ครอบบล็อกโค้ดเฉพาะข้อความที่โพสต์จริง ส่วนอธิบายอยู่นอกบล็อกเสมอ
- **คำสัญญาเรื่องราคา/ค่าธรรมเนียมที่เขียนจากความจำ** — ผิดครั้งเดียวแล้วถูกก๊อปซ้ำทุกชิ้นถัดไป
  **แก้:** ตรวจกับโค้ด/หน้าเว็บจริงทุกครั้ง ไม่มีข้อยกเว้น
- **หยิบตัวเลขด้านเดียว** — พาดหัวขัดกับงานวิจัยที่อ้างเอง
- **ลิงก์ชี้หน้าแรกเพราะยังไม่มีบทความ** — สัญญาณว่าข้ามขั้น 2
- **เอาคอนเทนต์ข่าวไปโพสต์ TikTok ทั้งที่ไบโอยังเป็นเรื่องอื่น** — คนกดไปเจอคนละเรื่อง
- **เวอร์ชันเดียวยิงทุกกลุ่ม** — ได้กลุ่มที่ engage เยอะแต่ไม่จ่าย
- **ตัวเลขในคลิปที่ยังไม่ได้ตรวจ** — แคปชันแก้ได้ คลิปแก้ไม่ได้

## E. Checklist ก่อนส่งมอบ

- [ ] ทุกตัวเลขมี URL ต้นทางที่เปิดดูแล้วเห็นจริง
- [ ] อ่านครบว่ามีตัวเลขอื่นในแหล่งเดียวกันที่ขัดกันไหม
- [ ] บทความปลายทางเปิดได้จริงจากมือถือ
- [ ] คอนเทนต์แยกครบทุกแพลตฟอร์มที่จะโพสต์ · ครอบบล็อกโค้ด
- [ ] URL เต็มทุกตัว ไม่มีแบบย่อ
- [ ] ไม่มีป้ายกำกับภายในหลงเหลือในบล็อกที่จะโพสต์
- [ ] คำสัญญาเรื่องเงินตรวจกับของจริงแล้ว
- [ ] ระบุแล้วว่าช่องไหนโพสต์ได้ตอนนี้ ช่องไหนต้องรอถึงวันไหน
- [ ] มีอย่างน้อย 2 เวอร์ชัน (มวลชน / คนที่จ่ายได้)
- [ ] อีเวนต์ปฏิทินมีข้อความเต็มในคำอธิบาย
- [ ] ไฟล์ฉากคลิปเปิดฉากด้วยชั้น 3 และมี URL สั้นในช่วงท้าย
