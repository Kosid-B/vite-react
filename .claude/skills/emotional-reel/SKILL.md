# Emotional Reel (สายดราม่า/โดนใจ) → 9:16 frames

ทำคอนเทนต์ Reel อารมณ์แบบไทย ๆ ที่ "พูดแทนใจคนดู" จนอยากแชร์ — ภาพเอสเธติก (ไล่สีพระอาทิตย์)
+ ข้อความค่อย ๆ เผยทีละบรรทัด + จบที่ความหวังจริง แล้วผูกแบรนด์แบบแผ่วเบา

ไฟล์ประกอบ (โฟลเดอร์นี้):
- `reel-template.html` — เทมเพลตเฟรม 9:16 (พื้นหลังไล่สี dusk/dawn + เงาขอบฟ้า + ข้อความ)
- `export-reel.mjs` — Playwright ตัดแต่ละ `.frame` เป็น PNG 1080×1920

## หลัก T.R.U.S.T. (บังคับ — คือเหตุผลที่คนอิน)
- **ขายแค่ "อารมณ์จริง"** — ไม่มีตัวเลข/สถิติ/เคลมปลอม ไม่มีความเร่งด่วนปลอม
- **จบที่ความหวังจริง** — ต้องเป็นสิ่งที่ทำได้จริง (เช่น "มีระบบช่วยคิด ช่วยทำ") ไม่ใช่คำสัญญาลม ๆ
- **ผูกแบรนด์แผ่วเบา** — โลโก้/ชื่อเล็ก ๆ เฟรมท้ายเท่านั้น ห้ามยัดขาย (ยัดขาย = ทำลายความจริงใจ = คนเลิกอิน)
- น้ำเสียงดิบ-จริง ("เรา/กู" ตามกลุ่ม) เหมือนเพื่อนพูด ไม่ใช่แบรนด์พูด

## โครงอารมณ์ (arc ที่ทำให้ปัง)
1. **Setup** (เปราะบาง) — เปิดด้วยความจริงที่คนกลุ่มนี้รู้สึกแต่ไม่พูด
2. **Pain** (2–3 เฟรม) — รายละเอียดที่ "โดน" (ยิ่งเฉพาะเจาะจง ยิ่งอิน)
3. **Open loop** — "จนวันหนึ่ง...เริ่มเข้าใจว่า…" (ค้างไว้ให้ดูต่อ)
4. **Realization** — จุดพลิกใจ (ปลดปล่อย)
5. **Hope + soft brand** — ความหวังจริง + ชื่อแบรนด์เล็ก ๆ
→ เปลี่ยนโทนพื้นหลัง **dusk (เย็นเหงา) → dawn (ฟ้าสาง)** ตาม arc = ภาพเล่าอารมณ์

## ขั้นตอน
1. รับ "กลุ่มเป้าหมาย + ความเจ็บปวด/อารมณ์" (เช่น เจ้าของธุรกิจเหงา, มือใหม่กลัวเริ่ม)
2. เขียนลำดับข้อความ 7–9 บรรทัดตาม arc ด้านบน (สั้น กระชับ ขึ้นบรรทัดใหม่ให้อ่านลื่น) — ยึด T.R.U.S.T.
3. คัด `reel-template.html` มาแก้: ใส่ข้อความในแต่ละ `.frame` · เฟรมช่วง pain ใช้ `class="frame dusk"` · ช่วง hope ใช้ `class="frame dawn"` · เฟรมท้ายใส่ `<div class="brand">ชื่อแบรนด์</div>`
4. Export: `node <skill-dir>/export-reel.mjs <reel.html> <out-dir>` → PNG 1080×1920 (01..)
5. ตรวจ 1–2 เฟรมด้วย Read (Thai render/เลย์เอาต์) · Chromium มีฟอนต์ไทย (TLWG) แล้ว
6. SendUserFile เฟรมทั้งหมด + **Caption** (อารมณ์ ไม่ขาย · #แฮชแท็กกลุ่มเป้าหมาย) + **โน้ตโพสต์**:
   - เฟรมละ 2.5–3 วิ, transition fade ช้า, เพลงเศร้า instrumental ที่ฮิตใน Reels
   - โพสต์เย็น–ค่ำ (20:00–22:00) ช่วงคนเหงา
   - จุดขาย = ประโยคจบที่ "อยากแชร์เพื่อพูดแทนใจ" = ตัวคูณไวรัล

## เคล็ด
- แชร์/เซฟสูงกว่าไลก์ = คอนเทนต์ปัง (คน "แชร์เพื่อพูดแทนใจ") — ออกแบบประโยคจบให้คนอยากแชร์
- เฉพาะเจาะจง > ทั่วไป ("นั่งเงียบคนเดียวตอนตีสอง" โดนกว่า "เหนื่อย")
