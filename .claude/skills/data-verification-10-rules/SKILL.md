# กฎตรวจสอบข้อมูล 3 ชั้น 10 ข้อ (Data Verification)

> **ใช้ทุกครั้งที่จะส่งตัวเลขออกไป** — ไม่ว่าจะเป็นคอนเทนต์ รายงาน ข้อเสนอ หรือคำตอบในแชท
>
> **หลักการที่ต้องจำ 4 คำ: บอกที่มา · บอกวันที่ · บอกขอบเขต · บอกข้อจำกัด**
> ถ้าไม่ครบ 4 → ต้องเตือนผู้อ่านให้ใช้ด้วยความระมัดระวังเสมอ

---

## A. หลักการหลัก

1. **ผู้ส่งข้อมูลต้องติดป้ายเอง ไม่ใช่รอให้ผู้รับจับได้**
   การส่งตัวเลขดิบแล้วให้อีกฝ่ายไปตรวจเอง = ผลักภาระและผลักความเสี่ยง
   คนที่หาข้อมูลมาคือคนที่รู้ดีที่สุดว่าตรงไหนมั่นใจ ตรงไหนไม่มั่นใจ — ต้องบอกออกมา

2. **🟡 ไม่ใช่ความล้มเหลว — 🟢 ปลอมต่างหากที่เป็น**
   การติดป้าย 🟡 ให้ตัวเลขที่ยังไม่แน่ใจ คือการทำงานถูกต้อง
   การติด 🟢 ให้ทุกอย่างเพื่อให้งานดูแน่น คือการโกหกแบบสุภาพ

3. **"ตรวจแล้ว" ต้องบอกได้ว่าตรวจถึงชั้นไหน**
   อ่านพาดหัว ≠ อ่านสรุปจากเครื่องมือค้นหา ≠ เปิดต้นฉบับอ่านเอง
   สามอย่างนี้ให้ความมั่นใจไม่เท่ากัน และต้องระบุว่าอยู่ชั้นไหน

4. **ข้อมูลมีวันหมดอายุไม่เท่ากัน**
   ราคาน้ำมัน/ทอง/ค่าเงิน = หมดอายุรายวัน · สถิติประชากร = รายปี · โครงสร้างกฎหมาย = หลายปี
   ตัวเลขที่หมดอายุเร็ว ต้องมีวันที่กำกับเสมอ ไม่มีข้อยกเว้น

## B. กฎ 10 ข้อ

### 🔍 ชั้นที่ 1 — ตรวจที่มา

| # | คำถาม | ตกเมื่อ |
|---|---|---|
| 1 | **แหล่งคือใคร?** ราชการ / มหาวิทยาลัย / สถาบันวิจัย / สื่อ / บุคคล | ไล่ไม่ถึงชื่อองค์กรที่รับผิดชอบตัวเลข |
| 2 | **มีลิงก์หรือเอกสารอ้างอิงไหม?** | ไม่มี → ระบุ "ยังไม่ยืนยันที่มา" |
| 3 | **เป็นข้อมูลล่าสุดไหม?** | เก่าเกิน 1 ปี → เตือน "อาจไม่ทันสมัย" · ข้อมูลรายวันเก่าเกิน 1 สัปดาห์ = ใช้ไม่ได้ |
| 4 | **แหล่งมีผลประโยชน์ทับซ้อนไหม?** | ผู้ขายสินค้านั้นเอง · วาณิชธนกิจที่มีสถานะในตลาดนั้น · ผู้ให้บริการที่ได้ประโยชน์จากตัวเลขสูง |

### 📊 ชั้นที่ 2 — ตรวจเนื้อหาและตัวเลข

| # | คำถาม | ตกเมื่อ |
|---|---|---|
| 5 | **ตัวเลขสมเหตุสมผลไหม?** | สูง/ต่ำผิดปกติจนต้องมีคำอธิบาย → "ต้องตรวจสอบเพิ่ม" |
| 6 | **มีหน่วยและขอบเขตชัดไหม?** | "คนจำนวนมาก" = ไม่ผ่าน · "393,073 คน ทั่วประเทศ ไตรมาส 1/2569" = ผ่าน |
| 7 | **สอดคล้องกับแหล่งอื่นไหม?** | แหล่ง 2 แห่งให้ตัวเลขต่างกันมาก → "ขัดแย้ง ต้องตรวจสอบ" ห้ามเลือกอันที่ถูกใจ |
| 8 | **เป็นข้อเท็จจริงหรือความเห็น?** | ความเห็น/การคาดการณ์ ต้องมี**ชื่อคนพูด**กำกับเสมอ ห้ามเขียนลอย ๆ |

### ✅ ชั้นที่ 3 — แจ้งผลอย่างโปร่งใส

**9. ติดป้ายระดับความเชื่อถือ**

| ป้าย | เกณฑ์ | ใช้ยังไง |
|---|---|---|
| 🟢 **ยืนยันได้** | แหล่งน่าเชื่อถือ + ตัวเลขชัด + สอดคล้องกัน ≥2 แหล่ง | ใช้ได้เลย ระบุแหล่ง+ปี |
| 🟡 **ใช้อย่างระวัง** | แหล่งไม่ชัด / ต้องตีความ / ยังไม่ได้เทียบแหล่งที่สอง / เป็นการคาดการณ์ | ใช้ได้ **แต่ต้องระบุแหล่งและขอบเขตในเนื้อหา** |
| 🔴 **ยังไม่ยืนยัน** | ขัดแย้งกัน / ไม่มีที่มา / ผิดปกติ | **ห้ามใช้** จนกว่าจะตรวจเพิ่ม |

**10. ระบุข้อจำกัดเสมอ** — "ข้อมูล ณ วันที่ … อาจเปลี่ยนแปลงได้"

## C. รูปแบบการส่งมอบ (ใช้ทุกครั้งที่ส่งตัวเลขให้ผู้ใช้)

```
| ข้อมูล | ป้าย | แหล่ง | วันที่ | ข้อจำกัด |
|---|---|---|---|---|
| Brent ~$88–90/บาร์เรล | 🟡 | Al Jazeera | 12 ส.ค. 69 | ราคารายวัน เปลี่ยนทุกวัน · ยังไม่ได้เทียบแหล่งที่สอง |
```

**ต้องแยกให้เห็นเสมอ:**
```
ข้อเท็จจริง : ฮอร์มุซปิดตั้งแต่ปลาย ก.พ. 2569        ← เกิดขึ้นแล้ว ตรวจได้
ความเห็น    : "Goldman มองว่า Brent จะยืนเหนือ $100"  ← มีชื่อคนพูด
ห้ามเขียน   : "ราคาน้ำมันจะทะลุ $100"                 ← เอาความเห็นมาเขียนเป็นข้อเท็จจริง
```

## D. ระดับความลึกของการตรวจ (ต้องระบุว่าอยู่ชั้นไหน)

| ชั้น | ทำอะไร | ป้ายสูงสุดที่ให้ได้ |
|---|---|---|
| 0 | เห็นในดราฟต์/โพสต์คนอื่น | 🔴 |
| 1 | อ่านพาดหัวจากผลค้นหา | 🔴 |
| 2 | อ่าน**สรุป**จากเครื่องมือค้นหา | 🟡 |
| 3 | เปิดต้นฉบับอ่านเอง 1 แหล่ง | 🟡 |
| 4 | เปิดต้นฉบับ ≥2 แหล่งอิสระ ตรงกัน | 🟢 |
| 5 | ต้นทางปฐมภูมิ (หน่วยงานเจ้าของตัวเลขเอง) | 🟢 |

> ⚠️ **ข้อจำกัดของสภาพแวดล้อมนี้:** บางโดเมนถูกบล็อกโดย network proxy
> (เคยเจอ: fortune.com, tradingeconomics.com, thairath.co.th, checkraka.app)
> เมื่อเปิดต้นฉบับไม่ได้ = ตรวจได้แค่**ชั้น 2** → **ป้ายสูงสุดคือ 🟡** ห้ามให้ 🟢
> และต้องบอกผู้ใช้ตรง ๆ ว่าเปิดต้นฉบับไม่ได้ เพื่อให้เขาตัดสินใจเองว่าจะเช็กซ้ำไหม

## E. Checklist ก่อนส่งตัวเลขออกไป

- [ ] ทุกตัวเลขมี **ชื่อองค์กรเจ้าของข้อมูล** ไม่ใช่แค่ชื่อสื่อที่เล่าต่อ
- [ ] ทุกตัวเลขมี **วันที่/ปี** กำกับ
- [ ] ตัวเลขที่หมดอายุเร็ว (ราคา/ค่าเงิน) ระบุวันที่ชัด + เตือนว่าเปลี่ยนได้
- [ ] **แยกข้อเท็จจริงออกจากการคาดการณ์** และการคาดการณ์มีชื่อคนพูด
- [ ] ตัวเลขที่ผิดปกติ → เทียบแหล่งที่สองแล้ว หรือติด 🟡/🔴
- [ ] **แหล่งที่มีผลประโยชน์ทับซ้อน ระบุไว้ด้วย** (เช่น วาณิชธนกิจพูดเรื่องราคาสินค้าโภคภัณฑ์)
- [ ] ติดป้าย 🟢/🟡/🔴 ครบทุกรายการ
- [ ] ระบุว่าตรวจถึง **ชั้นไหน** (ตาราง D) ถ้าเปิดต้นฉบับไม่ได้ต้องบอก
- [ ] มีบรรทัด "ข้อมูล ณ วันที่ … อาจเปลี่ยนแปลงได้"

## F. กับดักที่พบบ่อย

- **ติด 🟢 ให้ทุกอย่างเพราะอยากให้งานดูแน่น** — ผู้รับจะเลิกเชื่อป้ายทั้งระบบทันทีที่เจอ 🟢 ที่ผิดครั้งแรก
- **เอาความเห็นของคนดังมาเขียนเป็นข้อเท็จจริง** — "นักลงทุนชื่อดังบอกว่าทองจะขึ้น" ≠ "ทองจะขึ้น"
  (เคยพลาดจริง: ดราฟต์เขียน "ทองยังขึ้นต่อ" ขณะที่ทองลง 29.7% จากจุดสูงสุด)
- **ใช้ข้อมูลเก่าโดยไม่เช็กว่าสถานการณ์เปลี่ยนไปแล้ว** — เคยพลาดจริง: ดราฟต์เขียน
  "หากช่องแคบฮอร์มุซปิด" ทั้งที่ปิดไปแล้ว 5 เดือน = ประกาศว่าตามข่าวไม่ทัน
- **อ้างเพจ/แอคเคานต์ที่เล่าข่าวต่อ ว่าเป็น "รายงานระดับโลก"** — ต้องตามกลับไปหาต้นทาง
- **เดาตัวเลขในประเทศจากตัวเลขโลก** — เช่น น้ำมันโลกขึ้น → เดาว่าราคาหน้าปั๊มไทยขึ้นเท่านั้น
  ทั้งที่มีกองทุนน้ำมันพยุงราคา การส่งผ่านไม่ 1:1 · **คนหน้างานรู้ราคาจริงดีกว่าเราเสมอ**
- **ลืมว่าตัวเลขรายวันหมดอายุ** — ราคาที่ตรวจเมื่อวาน โพสต์วันนี้อาจผิดแล้ว
- **เลือกแหล่งที่ให้ตัวเลขถูกใจ เมื่อแหล่งขัดแย้งกัน** — ต้องรายงานว่าขัดแย้ง ไม่ใช่เลือกข้าง
