# tools/shortvideo — สร้างคลิปสั้นแนวตั้งจากไฟล์ฉาก (ไม่ต้องใช้โปรแกรมตัดต่อ)

ผลลัพธ์: MP4 แนวตั้ง **1080×1920 · 15 วินาที · H.264** ใช้ได้ทั้ง TikTok / Reels / YouTube Shorts

## ทำไมต้องมี

ทำคลิปด้วยมือทีละตัวช้าและไม่สม่ำเสมอ · วิธีนี้ **แก้ไฟล์ JSON ไฟล์เดียว = ได้คลิปใหม่**
ตัวหนังสือคมทุกเฟรม (เรนเดอร์จริง ไม่ใช่ภาพขยาย) และทุกคลิปหน้าตาเป็นชุดเดียวกันอัตโนมัติ

## ขั้นตอน (4 คำสั่ง)

```bash
# 0) ครั้งแรกครั้งเดียว — ต้องมีฟอนต์ Kanit + playwright + ffmpeg-static
npm i -D @fontsource/kanit playwright ffmpeg-static

# 1) JSON → HTML (ฝังฟอนต์เป็น base64 · แอนิเมชันผูกกับเวลาจริง)
python3 tools/shortvideo/makevid.py tools/shortvideo/scenes/<ชื่อ>.json /tmp/v.html

# 2) HTML → เฟรม PNG (หยุดแอนิเมชันแล้วตั้งเวลาทีละเฟรม = ได้ผลเหมือนเดิมทุกครั้ง)
node tools/shortvideo/capture.mjs /tmp/v.html /tmp/frames

# 3) เฟรม → MP4
npx ffmpeg -y -framerate 25 -i /tmp/frames/f%04d.png \
  -c:v libx264 -pix_fmt yuv420p -profile:v high -level 4.0 \
  -crf 20 -movflags +faststart -r 30 -an /tmp/out.mp4
```

## รูปแบบไฟล์ฉาก

```jsonc
{
  "duration": 15,                       // ความยาวคลิป (วินาที)
  "glow": "rgba(220,38,38,.18)",         // สีเรืองพื้นหลัง — ใช้สื่ออารมณ์ของเรื่อง
  "scenes": [
    { "in": 0, "out": 3.6, "lines": [    // ฉากโผล่ที่วินาที 0 หายที่ 3.6
      { "t": "บรรทัดแรก\nขึ้นบรรทัดใหม่ด้วย \\n", "cls": "big" },
      { "t": "โผล่ทีหลัง", "cls": "sub", "color": "#f87171", "at": 1.8 }
    ]}
  ]
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `cls` | `big` (พาดหัว) · `mid` (ข้อความหลัก) · `sub` (บรรทัดรอง) · `item` (รายการย่อย) |
| `at` | วินาทีที่บรรทัดนั้นโผล่ (ไม่ใส่ = โผล่พร้อมฉาก) |
| `size` / `color` / `mt` | ปรับเฉพาะบรรทัดนั้น |

## กติกาที่ต้องทำตาม (จาก skill `news-to-content-pipeline`)

- **3 วินาทีแรกต้องเป็นชั้น 3 (ความรู้สึก)** ไม่ใช่สถิติ ไม่ใช่ชื่อสินค้า
- **5 วินาทีสุดท้ายต้องมี URL สั้นบนจอ** ให้คนพิมพ์ตาม (เช่น `ceoaithailand.org/sms`)
- **เว้นขอบล่าง ~420px** — TikTok/Reels วางแคปชันและปุ่มทับ ข้อความจะโดนบัง
- **ห้ามใส่ URL ที่มี `?s=` ในคลิป** — ยาวเกินจะพิมพ์ตาม (ตัวเต็มไว้ใช้ในคำอธิบาย)
- **ห้ามใส่ตัวเลขที่ยังไม่ได้ตรวจแหล่ง** — คลิปแก้ย้อนหลังไม่ได้เหมือนแคปชัน

## ข้อควรรู้ทางเทคนิค

- ต้องใช้ **ffmpeg-static** — ffmpeg ที่มากับ Playwright เข้ารหัสได้แค่ VP8/WebM ซึ่งอัปขึ้น
  แพลตฟอร์มไม่ได้ทุกที่
- `capture.mjs` **หยุดแอนิเมชันแล้วตั้ง `currentTime` ทีละเฟรม** ไม่ใช่อัดหน้าจอ
  → ได้ไฟล์เหมือนเดิมทุกครั้งที่รัน และไม่มีเฟรมตกหล่นจากเครื่องช้า
- เส้นทาง Chromium ใน `capture.mjs` ผูกกับเวอร์ชันที่ติดตั้งไว้ ถ้ารันแล้วขึ้นว่าหาไม่เจอ
  ให้แก้ `executablePath` เป็นเวอร์ชันที่มีอยู่ใน `/opt/pw-browsers/`
